## 2. Модель прав в Linux

У каждого файла есть **владелец** (uid) и **группа** (gid). Для каждой из трёх категорий заданы три права:

| Категория | Кто это |
|-----------|---------|
| **u** (user) | Владелец файла |
| **g** (group) | Группа файла |
| **o** (others) | Все остальные |

| Право | Буква | Число | Что разрешает |
|-------|:-----:|:-----:|---------------|
| Чтение | `r` | 4 | Читать содержимое |
| Запись | `w` | 2 | Изменять содержимое |
| Выполнение | `x` | 1 | Запускать файл / входить в каталог |

**Пример:** `rwxr-xr--` = `754`:

| Категория | Права | Число |
|-----------|-------|:-----:|
| Владелец | `rwx` | 4+2+1 = 7 |
| Группа | `r-x` | 4+0+1 = 5 |
| Остальные | `r--` | 4+0+0 = 4 |

**Итого:** `754`.

## 3. `chmod` — изменить права

```c
#include <sys/stat.h>

int chmod(const char *pathname, mode_t mode);
int fchmod(int fd, mode_t mode);
```

| Функция | По чему работает |
|---------|------------------|
| `chmod` | По пути |
| `fchmod` | По дескриптору |

**Возвращает:** `0` при успехе, `-1` при ошибке.

**Пример:**

```c
#include <sys/stat.h>
#include <stdio.h>

int main(void)
{
    if (chmod("file.txt", 0644) == -1) {
        perror("chmod");
        return 1;
    }
    return 0;
}
```

⚠️ **`0644` с ведущим нулём** — восьмеричная запись. Без нуля `644` будет **десятичным** = `1204` в восьмеричной — совсем не то.

**Изменение через `fchmod`:**

```c
int fd = open("file.txt", O_RDONLY);
fchmod(fd, 0600);
close(fd);
```

**Правила:**
- Менять права может **владелец** или **root**.
- Обычный пользователь не может дать файлу права, которых у него самого нет.

## 4. Флаги прав `S_I*`

Числа `0644` — это удобно, но в коде часто используют **символические имена**:

| Флаг | Значение | Что означает |
|------|:--------:|--------------|
| `S_IRUSR` | 0400 | Чтение владельцем |
| `S_IWUSR` | 0200 | Запись владельцем |
| `S_IXUSR` | 0100 | Выполнение владельцем |
| `S_IRGRP` | 0040 | Чтение группой |
| `S_IWGRP` | 0020 | Запись группой |
| `S_IXGRP` | 0010 | Выполнение группой |
| `S_IROTH` | 0004 | Чтение остальными |
| `S_IWOTH` | 0002 | Запись остальными |
| `S_IXOTH` | 0001 | Выполнение остальными |

**Комбинирование через `|`:**

```c
chmod("script.sh",
      S_IRWXU |       // rwx для владельца (0700)
      S_IRGRP | S_IXGRP);  // r-x для группы (0050)
```

**Специальные биты:**

| Флаг | Значение | Что означает |
|------|:--------:|--------------|
| `S_ISUID` | 04000 | При запуске — права владельца |
| `S_ISGID` | 02000 | При запуске — права группы |
| `S_ISVTX` | 01000 | Sticky bit (только владелец может удалять) |

## 5. `chown` — изменить владельца

```c
#include <unistd.h>

int chown(const char *pathname, uid_t owner, gid_t group);
int fchown(int fd, uid_t owner, gid_t group);
int lchown(const char *pathname, uid_t owner, gid_t group);
```

| Функция | По чему работает | Ссылки |
|---------|------------------|--------|
| `chown` | По пути | Идёт по ссылке |
| `fchown` | По дескриптору | — |
| `lchown` | По пути | Не идёт по ссылке |

**Возвращает:** `0` или `-1`.

**Пример:**

```c
#include <unistd.h>
#include <stdio.h>

int main(void)
{
    if (chown("file.txt", 1000, 1000) == -1) {
        perror("chown");
        return 1;
    }
    return 0;
}
```

**Чтобы изменить только владельца** и не трогать группу, передайте `-1`:

```c
chown("file.txt", 1000, -1);   // только владелец
```

**Чтобы изменить только группу:**

```c
chown("file.txt", -1, 1000);
```

⚠️ **Только root может менять владельца.** Обычный пользователь может менять **группу** — и только на ту, в которой он состоит.

**Получить uid/gid текущего пользователя:**

```c
#include <unistd.h>
uid_t uid = getuid();
gid_t gid = getgid();
```

## 6. `umask` — маска создания файлов

Когда создаётся новый файл или каталог, ядро применяет **маску** — какие права **убрать**.

```c
#include <sys/stat.h>

mode_t umask(mode_t mask);
```

**Что делает:** устанавливает новую маску и возвращает **старую**.

**Пример:**

```c
mode_t old = umask(0022);   // запретить запись группе и остальным
// ... создаём файлы ...
umask(old);                 // возвращаем как было
```

**Как работает маска:**

```
Итоговые права = запрошенные права & ~umask
```

**Пример:** создаём файл через `open` с правами `0666`, umask = `0022`.

```
0666 = 110 110 110
0022 = 000 010 010  (инвертируем: 111 101 101)
─────────────────
итог = 110 100 100 = 0644
```

**Типичные маски:**

| Маска | Что делает | Итоговые права для файла |
|:-----:|-----------|:------------------------:|
| `0000` | Ничего не убирает | `0666` |
| `0022` | Убирает w у группы и остальных | `0644` |
| `0027` | Убирает w и r у остальных | `0640` |
| `0077` | Убирает всё у группы и остальных | `0600` |

---

## 7. Права по умолчанию

Когда вы создаёте файл через `open` с флагом `O_CREAT`, нужно указать **режим**:

```c
int fd = open("new.txt", O_WRONLY | O_CREAT, 0644);
```

⚠️ **Но итоговые права = `0644 & ~umask`.** Если umask = `0022`, получится `0644`. Если umask = `0077`, получится `0600`.

**Для каталогов:**

```c
mkdir("newdir", 0755);
```

Итоговые права — с учётом umask.

## 8. Полный пример: создание файла с нужными правами

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>

int main(void)
{
    // Устанавливаем маску — запрещаем доступ остальным
    mode_t old = umask(0077);

    int fd = open("secret.txt", O_WRONLY | O_CREAT | O_TRUNC, 0666);
    if (fd == -1) {
        perror("open");
        umask(old);
        return 1;
    }

    write(fd, "Hello\n", 6);
    close(fd);

    // Возвращаем маску
    umask(old);

    // Проверяем права
    struct stat st;
    stat("secret.txt", &st);
    printf("Права: %o\n", st.st_mode & 0777);   // 600

    return 0;
}
```

**Что произошло:**

1. `umask(0077)` — теперь при создании файлов права группы и остальных **убираются**.
2. `open(..., 0666)` — запрашиваем `0666`, но маска даёт `0600`.
3. Итоговые права — `0600` — только владелец может читать и писать.

## 9. Просмотр прав из программы

```c
#include <sys/stat.h>
#include <stdio.h>

struct stat st;
stat("file.txt", &st);

printf("Права: %o\n", st.st_mode & 0777);

if (st.st_mode & S_IRUSR) printf("Владелец может читать\n");
if (st.st_mode & S_IWUSR) printf("Владелец может писать\n");
if (st.st_mode & S_IXUSR) printf("Владелец может выполнять\n");
```

**Определение владельца:**

```c
printf("UID: %d\n", st.st_uid);
printf("GID: %d\n", st.st_gid);
```

## 10. Связь с shell

| Команда shell | Что делает |
|---------------|-----------|
| `chmod 755 file` | Права на файл |
| `chmod u+x file` | Добавить выполнение владельцу |
| `chown user:group file` | Сменить владельца и группу |
| `umask` | Показать текущую маску |
| `umask 022` | Установить маску |
| `ls -l` | Показать права |

**Пример вывода `ls -l`:**


## 11. Типичные ошибки

| Ошибка | Что не так | Решение |
|--------|-----------|---------|
| `chmod("file", 644)` | Десятичное, а не восьмеричное | `0644` |
| Забыли проверить `-1` | Работа с ошибкой | `if (chmod(...) == -1)` |
| `chown` для обычного пользователя | Нет прав | Только root |
| Забыли вернуть `umask` | Влияет на другие операции | Сохранить старое значение |
| `chmod` после `open` | Может быть позже, чем нужно | Использовать `fchmod` |
| Сравнение `st_mode == 0644` | Не учитывает тип файла | `(st.st_mode & 0777) == 0644` |
| `umask` как `0666` | Уберёт все права | `umask` — это **маска удаления**, а не установки |

## 12. Итоги

- **Права:** `r` = 4, `w` = 2, `x` = 1; три категории — владелец, группа, остальные.
- **`chmod`** — изменить права по пути.
- **`fchmod`** — изменить права по дескриптору.
- **`chown`** — изменить владельца (нужен root).
- **`fchown`**, **`lchown`** — варианты по дескриптору и без перехода по ссылкам.
- **`umask`** — маска, которая **убирает** права при создании.
- **Всегда пишите `0644`, а не `644`** — это восьмеричная запись.
- **Проверяйте `-1`** после каждого вызова.
