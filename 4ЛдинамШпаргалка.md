# Шпаргалка: функции управления памятью в C

Компактный справочник — печатайте и держите рядом.

---

## 🔹 Основные функции

| Функция | Заголовок | Что делает |
|---------|-----------|------------|
| `malloc(n)` | `<stdlib.h>` | Выделяет `n` байт в куче |
| `calloc(k, s)` | `<stdlib.h>` | Выделяет `k × s` байт и **обнуляет** |
| `realloc(p, n)` | `<stdlib.h>` | Меняет размер блока до `n` байт |
| `free(p)` | `<stdlib.h>` | Освобождает ранее выделенный блок |

---

## 🔹 malloc

```c
void *malloc(size_t size);
```

**Что делает:** выделяет `size` байт. Память **не обнуляется** — там мусор.

**Пример:**

```c
int *p = malloc(10 * sizeof(int));
if (p == NULL) {
    perror("malloc");
    return 1;
}
```

**Особенности:**
- Возвращает `NULL`, если памяти нет.
- Тип возврата — `void *`, приводить не обязательно (но можно).
- Всегда пишите `sizeof(тип)`, а не число.

---

## 🔹 calloc

```c
void *calloc(size_t count, size_t size);
```

**Что делает:** выделяет `count × size` байт и **обнуляет** их.

**Пример:**

```c
int *p = calloc(10, sizeof(int));   // 10 int, все = 0
```

**Когда использовать:**
- Нужны нули (счётчики, буферы).
- Для массивов структур — все поля = 0.

**Отличие от `malloc`:**

| | `malloc` | `calloc` |
|--|:--------:|:--------:|
| Обнуляет | ❌ | ✅ |
| Параметры | Байты | Элементы × размер |
| Скорость | Чуть быстрее | Чуть медленнее |

---

## 🔹 realloc

```c
void *realloc(void *ptr, size_t new_size);
```

**Что делает:** меняет размер блока. Данные **сохраняются**. Блок может **переместиться**.

**Правильное использование:**

```c
int *tmp = realloc(p, 20 * sizeof(int));
if (tmp == NULL) {
    free(p);         // старый блок ещё валиден
    return 1;
}
p = tmp;             // только теперь обновляем
```

⚠️ **Никогда не пишите `p = realloc(p, ...)`** — при `NULL` потеряете старый указатель и получите утечку.

**Особые случаи:**

| Вызов | Что означает |
|-------|--------------|
| `realloc(NULL, n)` | То же, что `malloc(n)` |
| `realloc(p, 0)` | Освобождает блок (по стандарту) |

**Когда использовать:**
- Динамический массив растёт.
- Чтение файла неизвестного размера.
- Буфер для накопления данных.

---

## 🔹 free

```c
void free(void *ptr);
```

**Что делает:** освобождает блок.

**Правило:**

```c
free(p);
p = NULL;      // защита от «висячего» указателя
```

**Особенности:**
- `free(NULL)` — **безопасно**, ничего не делает.
- Нельзя освободить дважды — UB.
- Нельзя освободить память не из `malloc`/`calloc`/`realloc`.
- Нельзя использовать память после `free`.

## 🔹 Шаблон работы с памятью

```c
// 1. Выделить
int *p = malloc(n * sizeof(int));
if (p == NULL) {
    perror("malloc");
    return 1;
}

// 2. Использовать
for (int i = 0; i < n; i++) {
    p[i] = i;
}

// 3. При необходимости расширить
int *tmp = realloc(p, 2 * n * sizeof(int));
if (tmp != NULL) {
    p = tmp;
    n *= 2;
}

// 4. Освободить
free(p);
p = NULL;
```

| Функция | Обнуляет | Сохраняет данные | Перемещает |
|---------|:--------:|:----------------:|:----------:|
| `malloc` | ❌ | — | — |
| `calloc` | ✅ | — | — |
| `realloc` | ❌ | ✅ | Может |
| `free` | — | — | — |

## 🔹 Размеры

**Правильно:**

```c
int *p = malloc(10 * sizeof(int));    // 10 int
struct Node *n = malloc(sizeof(struct Node));
char *s = malloc(strlen(str) + 1);    // +1 для '\0'
```

**Неправильно:**

```c
int *p = malloc(10);                  // ❌ 10 байт, а не 10 int
char *s = malloc(strlen(str));        // ❌ нет места для '\0'
int *p = malloc(n * sizeof(p));       // ❌ sizeof указателя, а не int
```

## 🔹 Типичные ошибки

| Ошибка | Что не так | Исправление |
|--------|-----------|-------------|
| Нет проверки `NULL` | Краш при нехватке памяти | `if (p == NULL) { ... }` |
| Забыли `free` | **Утечка** | Всегда `free(p)` |
| Двойное `free` | UB | `free(p); p = NULL;` |
| Использование после `free` | Мусор | Не обращаться |
| `p = realloc(p, ...)` | Утечка при `NULL` | Через `tmp` |
| `malloc(strlen(s))` без `+1` | Нет места для `\0` | `+1` |
| `sizeof(p)` для указателя | Даёт размер указателя | Считать вручную |
| `free` для стека | UB | Только для кучи |

## 🔹 Поиск утечек

**Valgrind:**

```bash
valgrind --leak-check=full ./app
```

Покажет:
- Утечки памяти.
- Использование после `free`.
- Неинициализированную память.

**AddressSanitizer:**

```bash
gcc -fsanitize=address -g -o app main.c
./app
```

Быстрее `valgrind`, встроен в GCC/Clang.

## 🔹 Динамические структуры

**Узел списка:**

```c
struct Node {
    int data;
    struct Node *next;
};

struct Node *head = malloc(sizeof(struct Node));
head->data = 10;
head->next = NULL;
```

**Двумерный массив:**

```c
int **m = malloc(rows * sizeof(int *));
for (int i = 0; i < rows; i++) {
    m[i] = malloc(cols * sizeof(int));
}

// освобождение
for (int i = 0; i < rows; i++) {
    free(m[i]);
}
free(m);
```

## 🔹 Шаблон роста массива

```c
int capacity = 2;
int size = 0;
int *arr = malloc(capacity * sizeof(int));

while (scanf("%d", &x) == 1) {
    if (size == capacity) {
        capacity *= 2;
        int *tmp = realloc(arr, capacity * sizeof(int));
        if (tmp == NULL) { free(arr); return 1; }
        arr = tmp;
    }
    arr[size++] = x;
}

free(arr);
```

**Идея:** удваиваем размер, когда массив заполнен. Так делают `vector` (C++), `list` (Python).

## 🔹 Сводка

| Что нужно | Функция |
|-----------|---------|
| Выделить память | `malloc(n)` |
| Выделить и обнулить | `calloc(k, s)` |
| Увеличить/уменьшить | `realloc(p, n)` |
| Освободить | `free(p)` |
| Проверить на ошибку | `if (p == NULL)` |
| Защита после `free` | `p = NULL` |
| Найти утечку | `valgrind` / ASan |

---

**Главное правило:** **сколько раз `malloc` — столько же раз `free`**. Если помнить это и проверять `NULL`, большинство проблем с памятью исчезнет. ✅
