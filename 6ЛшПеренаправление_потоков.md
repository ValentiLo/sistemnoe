# Шпаргалка: системные вызовы `pipe`, `dup`, `dup2`

Компактный справочник для быстрого повторения.

---

## 🔹 pipe — канал

```c
#include <unistd.h>

int pipe(int pipefd[2]);
```

**Что делает:** создаёт **однонаправленный** канал.

**Возвращает:**
- `0` — успех.
- `-1` — ошибка (`errno`).

**Дескрипторы:**

| Индекс | Назначение |
|:------:|------------|
| `pipefd[0]` | Читающий конец |
| `pipefd[1]` | Пишущий конец |

**Схема:**

```
Писатель → pipefd[1] ═══════► pipefd[0] → Читатель
```

⚠️ Канал **однонаправленный**. Для двустороннего — два канала.

## 🔹 dup / dup2 — дублирование дескрипторов

### dup

```c
int dup(int oldfd);
```

**Что делает:** копирует `oldfd` в **наименьший свободный** дескриптор.

**Возвращает:** новый дескриптор или `-1`.

**Пример:**

```c
int fd = open("data.txt", O_RDONLY);   // fd = 3
int copy = dup(fd);                    // copy = 4 — тот же файл
```

### dup2

```c
int dup2(int oldfd, int newfd);
```

**Что делает:** делает `newfd` копией `oldfd`. Если `newfd` открыт — **закрывает его**.

**Возвращает:** `newfd` или `-1`.

**Пример:**

```c
int fd = open("out.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
dup2(fd, 1);      // stdout → out.txt
close(fd);        // fd больше не нужен, но 1 остался

printf("Это в файле\n");
```

### Разница

| | `dup` | `dup2` |
|--|:-----:|:------:|
| Куда копирует | Наименьший свободный | В `newfd` |
| Старый дескриптор | Не трогает | Закрывает |
| Типичное применение | Сохранить ссылку | Подменить stdout/stdin |

---

## 🔹 Стандартные дескрипторы

| Дескриптор | Имя | Назначение |
|:----------:|-----|------------|
| 0 | `stdin` | Стандартный ввод |
| 1 | `stdout` | Стандартный вывод |
| 2 | `stderr` | Вывод ошибок |

Вместо чисел можно писать `STDIN_FILENO`, `STDOUT_FILENO`, `STDERR_FILENO`.

## 🔹 Шаблон: перенаправление stdout в файл

```c
int saved = dup(1);                    // сохраняем stdout

int fd = open("log.txt",
              O_WRONLY | O_CREAT | O_TRUNC,
              0644);
dup2(fd, 1);                           // stdout → файл
close(fd);

printf("Это в файле\n");
fflush(stdout);                        // сбрасываем буфер!

dup2(saved, 1);                        // восстанавливаем
close(saved);

printf("Это снова на экране\n");
```

⚠️ **`fflush(stdout)` обязателен** — иначе буфер уйдёт не туда.

---

## 🔹 Шаблон: перенаправление stdin из файла

```c
int fd = open("input.txt", O_RDONLY);
dup2(fd, 0);                           // stdin ← файл
close(fd);

char buf[100];
scanf("%s", buf);                      // читаем из файла
```

## 🔹 Шаблон: pipe между процессами

```c
int fd[2];
pipe(fd);                              // создаём канал

pid_t pid = fork();
if (pid == 0) {
    // Ребёнок — писатель
    close(fd[0]);                      // закрываем чтение
    const char *msg = "Hello";
    write(fd[1], msg, strlen(msg));
    close(fd[1]);
} else {
    // Родитель — читатель
    close(fd[1]);                      // закрываем запись
    char buf[100];
    ssize_t n = read(fd[0], buf, sizeof(buf) - 1);
    if (n > 0) {
        buf[n] = '\0';
        printf("Получено: %s\n", buf);
    }
    close(fd[0]);
    wait(NULL);
}
```

⚠️ **Правило:** в каждом процессе закрывайте **ненужный конец**. Иначе чтение зависнет.

## 🔹 Шаблон: мини-конвейер (как `ls | wc -l`)

```c
int fd[2];
pipe(fd);

pid_t pid = fork();
if (pid == 0) {
    // Ребёнок: пишем в pipe
    close(fd[0]);
    dup2(fd[1], 1);       // stdout → pipe
    close(fd[1]);
    execlp("ls", "ls", NULL);
} else {
    // Родитель: читаем из pipe
    close(fd[1]);
    dup2(fd[0], 0);       // stdin ← pipe
    close(fd[0]);
    execlp("wc", "wc", "-l", NULL);
}
```

Это **точно то, что делает shell** при `ls | wc -l`.

---

## 🔹 Как это делает shell

| Команда | Что реализует |
|---------|---------------|
| `ls > file` | `open` + `dup2` |
| `wc < file` | `open` + `dup2` |
| `ls \| wc` | `pipe` + `fork` + `dup2` |
| `ls > file 2>&1` | `dup2` дважды (1 и 2) |
| `ls >> file` | `open` с `O_APPEND` + `dup2` |

---

## 🔹 Связка read/write с pipe

| Функция | Что делает |
|---------|-----------|
| `write(fd[1], buf, n)` | Пишет в канал |
| `read(fd[0], buf, n)` | Читает из канала |
| `close(fd[1])` | Закрывает запись → читатель получит `EOF` |
| `close(fd[0])` | Закрывает чтение → писатель получит `SIGPIPE` |

⚠️ Если **все** пишущие концы закрыты, `read` вернёт `0` (EOF).

## 🔹 Полезные системные вызовы рядом

| Функция | Что делает |
|---------|-----------|
| `fork()` | Создаёт процесс |
| `exec*()` | Заменяет программу |
| `wait()` | Ждёт завершения ребёнка |
| `open`, `close` | Открыть/закрыть файл |
| `read`, `write` | Чтение/запись |
| `fcntl(fd, F_SETFL, O_NONBLOCK)` | Неблокирующий режим |
| `fileno(FILE*)` | Получить дескриптор из `FILE *` |
| `fdopen(fd, mode)` | Получить `FILE *` из дескриптора |

## 🔹 Типичные ошибки

| Ошибка | Что не так | Решение |
|--------|-----------|---------|
| Забыли `fflush` перед `dup2` | Буфер уйдёт не туда | `fflush(stdout);` |
| Не закрыли `fd` после `dup2` | Утечка дескриптора | `close(fd);` |
| Оставили оба конца `pipe` | Чтение зависнет | Закрыть ненужный конец |
| Забыли проверить `-1` | Работа с невалидным дескриптором | `if (fd == -1) { ... }` |
| Не сохранили старый дескриптор | Нельзя восстановить | `saved = dup(1);` |
| Игнорирование ошибок `read`/`write` | Потеря данных | Проверять `n` |

## 🔹 Шаблон «сохранить → подменить → восстановить»

```c
int saved_out = dup(1);                // сохраняем stdout
int saved_in  = dup(0);                // сохраняем stdin

int fd_out = open("out.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
dup2(fd_out, 1);
close(fd_out);

int fd_in = open("in.txt", O_RDONLY);
dup2(fd_in, 0);
close(fd_in);

// ... работаем: printf пишет в out.txt, scanf читает из in.txt ...
fflush(stdout);

dup2(saved_out, 1);                    // восстанавливаем
dup2(saved_in, 0);
close(saved_out);
close(saved_in);
```

## 🔹 Сводка

| Что нужно | Функция |
|-----------|---------|
| Создать канал | `pipe(fd)` |
| Дублировать дескриптор | `dup(fd)` |
| Подменить дескриптор | `dup2(oldfd, newfd)` |
| Перенаправить stdout | `dup2(fd, 1)` |
| Перенаправить stdin | `dup2(fd, 0)` |
| Восстановить | `dup2(saved, 1)` |
| Закрыть | `close(fd)` |
| Прочитать из канала | `read(fd[0], buf, n)` |
| Записать в канал | `write(fd[1], buf, n)` |

---

**Главное правило:** **`pipe` + `fork` + `dup2`** — это три кита, на которых стоит вся командная строка Linux. Освоив их, вы поймёте, как устроены конвейеры, перенаправления и взаимодействие процессов.
