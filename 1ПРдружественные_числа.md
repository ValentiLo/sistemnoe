Разберём задачу на **дружественные числа** подробно.

## Что такое дружественные числа

Два **различных** натуральных числа `a` и `b` называются дружественными, если:

- сумма **собственных** делителей `a` равна `b`
- сумма **собственных** делителей `b` равна `a`

**Собственные делители** — это все положительные делители числа, **кроме самого числа**.

**Классический пример:** `220` и `284`.

- Делители 220 (без 220): 1, 2, 4, 5, 10, 11, 20, 22, 44, 55, 110 → сумма = **284**
- Делители 284 (без 284): 1, 2, 4, 71, 142 → сумма = **220**

---

## Ошибочное решение

```c
int sumOfDivisors(int n) {
    int sum = 0;
    for (int i = 1; i <= n / 2; i++) {
        if (n % i == 0) sum += i;
    }
    return sum;
}
```

**Проблемы:**

1. **Цикл до `n / 2`** — это работает, но медленнее, чем до `√n`. Для учебной задачи допустимо, но не оптимально.
2. **Нет проверки `a != b`** — если `a == b`, программа может сказать «дружественные» для совершенного числа (например, 6 и 6), хотя по определению числа должны быть **различными**.
3. **Нет проверки на `n <= 0`** — для нуля и отрицательных поведение не определено.
4. **Тип `int`** — при больших числах сумма делителей может переполниться. Лучше `long long`.

 сам код требует доработки.

## Как надо — правильная реализация

### Вариант 1. Простой (перебор до `n / 2`)

```c
#include <stdio.h>

long long sum_proper_divisors(int n) {
    if (n <= 1) return 0;          // у 0 и 1 нет собственных делителей
    long long sum = 1;             // 1 — собственный делитель любого n > 1
    for (int d = 2; d <= n / 2; ++d) {
        if (n % d == 0) sum += d;
    }
    return sum;
}

int are_amicable(int a, int b) {
    if (a <= 0 || b <= 0) return 0;   // только натуральные
    if (a == b) return 0;             // числа должны быть различными
    return sum_proper_divisors(a) == b &&
           sum_proper_divisors(b) == a;
}

int main(void) {
    int a, b;
    if (scanf("%d %d", &a, &b) != 2) return 1;
    puts(are_amicable(a, b) ? "Дружественные" : "Не дружественные");
    return 0;
}
```

**Проверка:** ввод `220 284` → «Дружественные».

### Вариант 2. Оптимизированный (перебор до `√n`)

```c
#include <stdio.h>

long long sum_proper_divisors(int n) {
    if (n <= 1) return 0;
    long long sum = 1;
    for (int d = 2; (long long)d * d <= n; ++d) {
        if (n % d == 0) {
            sum += d;
            if (d != n / d) sum += n / d;   // парный делитель
        }
    }
    return sum;
}

int are_amicable(int a, int b) {
    if (a <= 0 || b <= 0) return 0;
    if (a == b) return 0;
    return sum_proper_divisors(a) == b &&
           sum_proper_divisors(b) == a;
}

int main(void) {
    int a, b;
    if (scanf("%d %d", &a, &b) != 2) return 1;
    puts(are_amicable(a, b) ? "Дружественные" : "Не дружественные");
    return 0;
}
```

Здесь сложность O(√n) вместо O(n), и корректно обрабатываются парные делители (например, для 28: делители 2 и 14, 4 и 7).

## Разбор ошибок в исходном коде

| Проблема | Последствие | Как исправить |
|---|---|---|
| Нет проверки `a == b` | 6 и 6 → «дружественные» (неверно) | Добавить `if (a == b) return 0;` |
| Нет проверки `n <= 0` | Для 0 и отрицательных — мусор | Добавить `if (n <= 1) return 0;` |
| Тип `int` | Переполнение при больших n | Заменить на `long long` |
| Цикл до `n / 2` | Медленно, но корректно | Можно оставить или оптимизировать до `√n` |
| Нет `#include <stdio.h>`? | — | В отчёте есть, всё в порядке |

## Что исправить в отчёте

1. **Добавить проверку `a == b`** — иначе 6 и 6 дадут ложное срабатывание.
2. **Добавить проверку `a > 0 && b > 0`** — защита от нуля и отрицательных.
3. **Заменить `int sum` на `long long sum`** — на будущее.
4. **В пояснении написать**, что сумма считается **без самого числа** (собственные делители).
5. **Привести пример** `220 284` → «Дружественные» — это нагляднее, чем `6 10`.
