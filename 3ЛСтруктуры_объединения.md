## 2. Зачем нужны структуры

До этого мы работали с отдельными переменными: одно число, одна строка, один флаг. Но в реальных задачах данные редко существуют по отдельности. У студента есть имя, возраст, группа и средний балл. У товара — название, цена, количество. Хранить всё это в разных переменных неудобно: их легко перепутать, сложно передавать в функции, тяжело хранить в массивах.

**Структура** позволяет объединить несколько переменных разных типов под одним именем. Это как анкета: у неё есть поля, и все они относятся к одному человеку.

---

## 3. Объявление структуры

```c
struct Student {
    char name[50];
    int age;
    int group;
    double average;
};
```

Здесь `struct Student` — это **новый тип данных**, который мы сами определили. Он состоит из четырёх полей. Обратите внимание на точку с запятой после закрывающей скобки — её часто забывают.

После объявления можно создавать переменные этого типа:

```c
struct Student s1;
struct Student s2, s3;
```

---

## 4. Инициализация и доступ к полям

Доступ к полям осуществляется через точку `.`:

```c
struct Student s;

strcpy(s.name, "Иванов И.И.");
s.age = 18;
s.group = 214;
s.average = 4.5;

printf("%s, %d лет, группа %d, средний балл %.2f\n",
       s.name, s.age, s.group, s.average);
```

Можно инициализировать сразу при объявлении — по порядку полей:

```c
struct Student s = {"Иванов И.И.", 18, 214, 4.5};
```

Или с указанием имён полей (так надёжнее — не зависит от порядка):

```c
struct Student s = {
    .name = "Иванов И.И.",
    .age = 18,
    .group = 214,
    .average = 4.5
};
```

---

## 5. Массивы структур

Структуры удобно хранить в массивах — например, список студентов группы:

```c
struct Student group[30];

group[0].age = 18;
strcpy(group[0].name, "Петров П.П.");
```

Обход массива структур:

```c
for (int i = 0; i < 30; i++) {
    printf("%s — %d\n", group[i].name, group[i].age);
}
```

---

## 6. Указатели на структуры

Если структура большая, передавать её в функцию по значению невыгодно — копируется весь блок памяти. Лучше передавать **указатель**.

```c
void print_student(struct Student *s) {
    printf("%s, %d лет\n", s->name, s->age);
}
```

Обратите внимание на оператор `->`. Он заменяет `(*s).name`:

| Запись | Что означает |
|--------|--------------|
| `s.name` | Поле структуры (когда `s` — сама структура) |
| `s->name` | Поле структуры (когда `s` — указатель) |
| `(*s).name` | То же, что `s->name`, но громоздко |

Вызов функции:

```c
struct Student s = {"Иванов И.И.", 18, 214, 4.5};
print_student(&s);   // передаём адрес
```

## 7. Объединения (`union`)

**Объединение** похоже на структуру, но с одним важным отличием: **все поля разделяют одну и ту же память**. Размер объединения равен размеру самого большого поля.

```c
union Value {
    int i;
    float f;
    char c;
};
```

Здесь `Value` может хранить **либо** `int`, **либо** `float`, **либо** `char` — но не всё сразу. Если записать `i`, то `f` и `c` будут содержать «мусор» из тех же байтов.

```c
union Value v;
v.i = 42;
printf("%d\n", v.i);     // 42
printf("%f\n", v.f);     // непредсказуемое значение
```

**Размер:**

```c
printf("%zu\n", sizeof(union Value));   // обычно 4 (размер int/float)
printf("%zu\n", sizeof(struct Student)); // сумма всех полей + выравнивание
```

### Когда использовать `union`

- Когда нужно **экономить память** — например, хранить в одной ячейке либо число, либо строку.
- Когда данные **взаимоисключающие** — либо одно, либо другое.
- Для **низкоуровневых трюков** — например, посмотреть байты `float` как `int`.

**Пример: тег + значение**

```c
struct Variant {
    int type;         // 0 = int, 1 = float
    union {
        int i;
        float f;
    } value;
};
```

Теперь `value` занимает столько же, сколько самое большое поле, а `type` говорит, что именно там лежит.

## 8. `typedef` — упрощаем имена

`typedef` позволяет дать типу **новое имя**. Это особенно удобно для структур: не нужно каждый раз писать `struct Student`.

```c
typedef struct Student {
    char name[50];
    int age;
} Student;
```

Теперь можно писать просто:

```c
Student s1;
Student group[30];
```

Без `typedef` пришлось бы писать `struct Student s1;`. Это не ошибка, но длиннее.

**Ещё примеры:**

```c
typedef unsigned int uint;
typedef int *IntPtr;
typedef int Matrix[3][3];
```

Использование:

```c
uint x = 42;
IntPtr p = &x;
Matrix m;
```

⚠️ **`typedef` не создаёт новый тип** — он лишь даёт синоним. Компилятор видит за ним исходный тип.

## 9. Сравнение: `struct` vs `union`

| Критерий | `struct` | `union` |
|----------|----------|---------|
| Память | Каждое поле — своё место | Все поля делят одно место |
| Размер | Сумма полей (+ выравнивание) | Максимум из полей |
| Одновременный доступ | Можно ко всем полям | Только к одному |
| Применение | Анкеты, записи, объекты | Варианты, экономия памяти |
| Доступ | `.` или `->` | `.` или `->` |

---

## 10. Выравнивание (padding)

Компилятор может вставлять **пустые байты** между полями структуры, чтобы выровнять их по границам. Это влияет на размер.

```c
struct A {
    char c;    // 1 байт
    int i;     // 4 байта, но с выравниванием
};

printf("%zu\n", sizeof(struct A));   // часто 8, а не 5
```

Порядок полей может уменьшить размер:

```c
struct B {
    int i;     // 4
    char c;    // 1 + 3 выравнивания
};              // тоже 8
```

**Вывод:** если важна экономия памяти, располагайте поля **от большего к меньшему**.

## 11. Пример: база студентов

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char name[50];
    int age;
    int group;
    double average;
} Student;

void print_student(const Student *s) {
    printf("%-20s %2d лет, группа %d, средний %.2f\n",
           s->name, s->age, s->group, s->average);
}

int main(void) {
    Student group[3] = {
        {"Иванов И.И.",   18, 214, 4.5},
        {"Петров П.П.",   19, 214, 3.8},
        {"Сидоров С.С.",  18, 215, 4.9}
    };

    for (int i = 0; i < 3; i++) {
        print_student(&group[i]);
    }

    return 0;
}
```

**Вывод:**

```
Иванов И.И.           18 лет, группа 214, средний 4.50
Петров П.П.           19 лет, группа 214, средний 3.80
Сидоров С.С.          18 лет, группа 215, средний 4.90
```

## 12. Типичные ошибки

| Ошибка | Что не так |
|--------|-----------|
| `struct Student s; s = {"Иванов", 18};` | Присваивание списка после объявления не работает |
| `s->name` для обычной структуры | `->` только для указателей |
| `s.name` для указателя | Нужно `s->name` или `(*s).name` |
| Забыли `;` после `}` | Синтаксическая ошибка |
| Сравнение структур через `==` | Не работает, нужно сравнивать поля по отдельности |
| `strcpy(s.name, "текст")` | Для массива строк — только `strcpy` |
| Доступ к «не тому» полю `union` | Данные непредсказуемы |

---

## 13. Итоги

- **`struct`** — объединяет поля разных типов, каждое занимает своё место.
- **`union`** — поля делят одну память; хранится только одно значение.
- Доступ через `.` для структур, через `->` для указателей.
- **`typedef`** даёт типу короткое имя — особенно удобно для структур.
- **Выравнивание** может увеличивать размер структуры.
- Структуры передавайте в функции **по указателю** — это эффективнее.
