## 2. Что такое каталог

**Каталог** (директория) — это специальный файл, который хранит **список имён** и **ссылки на inode** файлов, которые в нём лежат.

С точки зрения программы каталог — это **поток** таких же записей, как и обычный файл. Только читать его нужно специальными функциями из `<dirent.h>`.

**Основные функции:**

| Функция | Что делает |
|---------|-----------|
| `opendir` | Открывает каталог |
| `readdir` | Читает следующую запись |
| `closedir` | Закрывает каталог |
| `chdir` | Меняет текущий каталог |
| `getcwd` | Возвращает текущий каталог |

---

## 3. `opendir` — открыть каталог

```c
#include <dirent.h>

DIR *opendir(const char *name);
```

**Что делает:** открывает каталог по имени и возвращает указатель на `DIR`.

**Возвращает:** указатель или `NULL` при ошибке.

**Пример:**

```c
DIR *dir = opendir(".");
if (dir == NULL) {
    perror("opendir");
    return 1;
}
```

`"."` — текущий каталог, `".."` — родительский, `"/home/user"` — абсолютный путь.

**Тип `DIR`** — непрозрачная структура, работает как `FILE` для файлов.

---

## 4. `readdir` — читать записи

```c
struct dirent *readdir(DIR *dirp);
```

**Что делает:** возвращает указатель на **следующую** запись в каталоге.

**Возвращает:** `struct dirent *` или `NULL`, когда записи закончились (или ошибка).

**Структура `struct dirent`:**

```c
struct dirent {
    ino_t          d_ino;       // номер inode
    off_t          d_off;       // смещение следующей записи
    unsigned short d_reclen;    // длина записи
    unsigned char  d_type;      // тип файла
    char           d_name[];    // имя файла
};
```

**Основные поля:**

| Поле | Что содержит |
|------|--------------|
| `d_name` | Имя файла (строка) |
| `d_ino` | Номер inode |
| `d_type` | Тип: `DT_REG`, `DT_DIR`, `DT_LNK`, `DT_CHR`, `DT_BLK`, `DT_FIFO`, `DT_SOCK` |

⚠️ **`d_type` поддерживается не всеми файловыми системами.** Если он равен `DT_UNKNOWN` — используйте `stat`/`lstat` для определения типа.

**Пример обхода:**

```c
struct dirent *entry;
while ((entry = readdir(dir)) != NULL) {
    printf("%s\n", entry->d_name);
}
```

⚠️ **`readdir` возвращает `.` и `..`** — их обычно нужно пропускать:

```c
if (strcmp(entry->d_name, ".") == 0 ||
    strcmp(entry->d_name, "..") == 0)
    continue;
```

## 5. `closedir` — закрыть каталог

```c
int closedir(DIR *dirp);
```

**Что делает:** закрывает каталог, освобождает ресурсы.

**Возвращает:** `0` при успехе, `-1` при ошибке.

**Пример:**

```c
closedir(dir);
```

⚠️ **Всегда закрывайте** — иначе утечка дескрипторов.

---

## 6. `chdir` — сменить текущий каталог

```c
#include <unistd.h>

int chdir(const char *path);
```

**Что делает:** меняет текущий рабочий каталог процесса на `path`.

**Возвращает:** `0` при успехе, `-1` при ошибке.

**Пример:**

```c
if (chdir("/tmp") == -1) {
    perror("chdir");
    return 1;
}
```

⚠️ **`chdir` влияет только на текущий процесс.** Родительский shell остаётся там же.

---

## 7. `getcwd` — текущий каталог

```c
char *getcwd(char *buf, size_t size);
```

**Что делает:** возвращает **абсолютный путь** текущего каталога в `buf`.

**Возвращает:** `buf` или `NULL` при ошибке (если буфер мал).

**Пример:**

```c
char cwd[1024];
if (getcwd(cwd, sizeof(cwd)) == NULL) {
    perror("getcwd");
    return 1;
}
printf("Текущий каталог: %s\n", cwd);
```

⚠️ **Буфер должен быть достаточного размера.** Обычно хватает `PATH_MAX` (4096), определённой в `<limits.h>`.

---

## 8. Полный пример: вывод содержимого каталога

```c
#include <stdio.h>
#include <dirent.h>
#include <string.h>

int main(int argc, char *argv[])
{
    const char *path = (argc > 1) ? argv[1] : ".";

    DIR *dir = opendir(path);
    if (dir == NULL) {
        perror("opendir");
        return 1;
    }

    struct dirent *entry;
    while ((entry = readdir(dir)) != NULL) {
        if (strcmp(entry->d_name, ".") == 0 ||
            strcmp(entry->d_name, "..") == 0)
            continue;

        printf("%s\n", entry->d_name);
    }

    closedir(dir);
    return 0;
}
```

**Запуск:**

```
$ ./ls .
main.c
Makefile
data.txt
```

## 9. Определение типа файла

Простой способ — через `d_type`:

```c
switch (entry->d_type) {
    case DT_REG: printf("[F] "); break;
    case DT_DIR: printf("[D] "); break;
    case DT_LNK: printf("[L] "); break;
    default:     printf("[?] "); break;
}
```

**Надёжный способ** — через `stat`/`lstat` (если `d_type == DT_UNKNOWN`):

```c
struct stat st;
char fullpath[PATH_MAX];
snprintf(fullpath, sizeof(fullpath), "%s/%s", path, entry->d_name);

if (lstat(fullpath, &st) == 0) {
    if (S_ISDIR(st.st_mode)) printf("[D] ");
    else if (S_ISREG(st.st_mode)) printf("[F] ");
    else if (S_ISLNK(st.st_mode)) printf("[L] ");
}
```

## 10. Рекурсивный обход

Чтобы пройти по всем вложенным каталогам, функцию вызывают рекурсивно:

```c
void walk(const char *path)
{
    DIR *dir = opendir(path);
    if (dir == NULL) return;

    struct dirent *entry;
    while ((entry = readdir(dir)) != NULL) {
        if (strcmp(entry->d_name, ".") == 0 ||
            strcmp(entry->d_name, "..") == 0)
            continue;

        char fullpath[PATH_MAX];
        snprintf(fullpath, sizeof(fullpath), "%s/%s", path, entry->d_name);

        printf("%s\n", fullpath);

        if (entry->d_type == DT_DIR) {
            walk(fullpath);
        }
    }
    closedir(dir);
}
```

⚠️ **Осторожно с символическими ссылками** — они могут вызвать бесконечную рекурсию. Используйте `lstat` и пропускайте `DT_LNK`, если это ссылка на каталог.

## 11. Полезные функции рядом

| Функция | Что делает |
|---------|-----------|
| `mkdir(path, mode)` | Создать каталог |
| `rmdir(path)` | Удалить пустой каталог |
| `remove(path)` | Удалить файл |
| `rename(old, new)` | Переименовать/переместить |
| `realpath(path, buf)` | Абсолютный путь без ссылок |
| `basename(path)` | Имя файла без пути |
| `dirname(path)` | Путь без имени файла |

**Пример:**

```c
mkdir("newdir", 0755);
```

## 12. Типичные ошибки

| Ошибка | Что не так | Решение |
|--------|-----------|---------|
| Нет проверки `opendir == NULL` | Краш | Проверять всегда |
| Забыли `closedir` | Утечка дескрипторов | Всегда закрывать |
| Не пропускают `.` и `..` | Лишние записи | `strcmp` |
| Используют `d_type` без проверки | На некоторых ФС `DT_UNKNOWN` | Использовать `stat` |
| `chdir` в цикле без возврата | Непредсказуемое поведение | Сохранять `getcwd` |
| Маленький буфер для `getcwd` | `NULL` при переполнении | Использовать `PATH_MAX` |
| Рекурсия по ссылкам | Бесконечный цикл | Пропускать `DT_LNK` |

## 13. Итоги

- **`opendir`** — открыть каталог.
- **`readdir`** — читать записи по одной; возвращает `NULL` в конце.
- **`closedir`** — закрыть каталог.
- **`chdir`** — сменить текущий каталог.
- **`getcwd`** — узнать текущий каталог.
- **`struct dirent`** содержит имя и тип файла.
- **Рекурсия** позволяет обойти всё дерево каталогов.
- **Всегда проверяйте** `NULL` и закрывайте каталог.
