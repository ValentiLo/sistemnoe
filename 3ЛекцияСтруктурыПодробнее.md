## 2. Что такое структура

### 2.1. Определение

**Структура (`struct`)** — это составной тип данных, который объединяет **несколько переменных разных типов** под одним именем. Каждая переменная внутри структуры называется **полем** (или **членом**).

Структура позволяет описать **объект реального мира** одним типом. Например, студент имеет:
- имя (строка),
- возраст (целое),
- средний балл (вещественное).

Без структуры пришлось бы заводить три отдельные переменные. Со структурой — одну.

### 2.2. Синтаксис объявления

```c
struct Student {
    char name[50];   // поле 1: имя
    int age;         // поле 2: возраст
    double average;  // поле 3: средний балл
};
```

**Разбор:**
- `struct` — ключевое слово.
- `Student` — **имя типа** (тег структуры). Принято писать с большой буквы.
- `{ ... }` — тело структуры со списком полей.
- `;` — **обязательна** после закрывающей скобки.

После этого `struct Student` — это **новый тип данных**, такой же, как `int` или `double`.

## 3. Что такое `s` в `struct Student s;`

Это **ключевой момент**, который часто вызывает путаницу. Разберём по частям.

### 3.1. Аналогия с обычными типами

Сравните:

```c
int x;              // x — переменная типа int
struct Student s;   // s — переменная типа struct Student
```

| Что | В `int x;` | В `struct Student s;` |
|---|---|---|
| **Тип** | `int` | `struct Student` |
| **Имя переменной** | `x` | `s` |
| **Что хранится** | одно целое число | три поля: `name`, `age`, `average` |

**`s` — это имя переменной** (экземпляра структуры). Не тип, не поле, не тег. Просто имя конкретного «студента».

### 3.2. Что происходит в памяти

Когда вы пишете `struct Student s;`, компилятор **выделяет память** под все поля структуры:

```
s (struct Student)
┌──────────────────────┐
│ name[50]   → 50 байт │
│ age        →  4 байта│
│ average    →  8 байт │
└──────────────────────┘
Итого: ~64 байта (с выравниванием)
```

**`s` — это имя блока памяти**, в котором лежат три поля. Обращаться к ним можно через `s.name`, `s.age`, `s.average`.

### 3.3. Можно объявить несколько переменных

```c
struct Student s1;   // первый студент
struct Student s2;   // второй студент
struct Student group[30];  // массив из 30 студентов
```

Каждая переменная (`s1`, `s2`, `group[0]`, …) — **отдельный экземпляр** со своими значениями полей. Тип у них один — `struct Student`.

## 4. Инициализация структуры

### 4.1. Поэлементно

```c
struct Student s;
s.age = 18;
s.average = 4.5;
strcpy(s.name, "Иван");   // для строк — strcpy, а не =
```

### 4.2. При объявлении (списком)

```c
struct Student s = {"Иван", 18, 4.5};
```

Порядок значений — **строго как в объявлении структуры**.

### 4.3. С указанием полей (C99+)

```c
struct Student s = {
    .name = "Иван",
    .age = 18,
    .average = 4.5
};
```

Удобно, когда полей много или порядок неочевиден.

---

## 5. Доступ к полям

### 5.1. Через точку (для переменной)

```c
struct Student s;
s.age = 18;                     // запись
printf("%d\n", s.age);          // чтение
```

### 5.2. Через стрелку (для указателя)

```c
struct Student s;
struct Student *p = &s;   // p — указатель на s
p->age = 18;              // то же, что (*p).age = 18
printf("%d\n", p->age);
```

**Правило:**
- `s.age` — если `s` это переменная.
- `p->age` — если `p` это указатель.
- `(*p).age` — эквивалент `p->age`, но писать дольше.

## 6. Передача структур в функции

### 6.1. По значению (копия)

```c
void printStudent(struct Student s) {
    printf("%s, %d, %.2f\n", s.name, s.age, s.average);
}
```

При вызове структура **копируется целиком**. Для больших структур это **дорого** по памяти и времени.

### 6.2. По указателю (рекомендуется)

```c
void printStudent(const struct Student *s) {
    printf("%s, %d, %.2f\n", s->name, s->age, s->average);
}
```

Копируется только **адрес** (8 байт), а не вся структура. `const` защищает от случайного изменения.

### 6.3. Пример с изменением

```c
void birthday(struct Student *s) {
    s->age += 1;   // изменяет исходную структуру
}

int main(void) {
    struct Student s = {"Иван", 18, 4.5};
    birthday(&s);
    printf("%d\n", s.age);   // 19
    return 0;
}
```

## 7. `typedef` — упрощение синтаксиса

Писать `struct Student` каждый раз утомительно. `typedef` создаёт **псевдоним**:

```c
typedef struct Student {
    char name[50];
    int age;
    double average;
} Student;
```

Теперь можно писать:

```c
Student s;          // вместо struct Student s
Student group[30];
```

Это **стиль современного C**. Часто имя тега и псевдонима делают одинаковыми (`Student` / `Student`).

## 8. Объединения (`union`)

### 8.1. Определение

**Объединение (`union`)** — это тип, в котором **все поля разделяют одну и ту же память**. В каждый момент времени хранится **только одно** значение.

### 8.2. Синтаксис

```c
union Value {
    int i;
    float f;
    char c;
};
```

### 8.3. Как это работает в памяти

```
union Value v;
┌──────────────┐
│ i  ┐         │
│ f  ├─ одна и │
│ c  ┘  та же  │
│      память  │
└──────────────┘
Размер = max(sizeof(int), sizeof(float), sizeof(char)) = 4 байта
```

Все три поля **начинаются с одного адреса**. Если записать `v.i = 5`, а потом прочитать `v.f` — получите **интерпретацию тех же байтов** как `float`. Это часто даёт «мусор».

### 8.4. Пример

```c
union Value v;
v.i = 65;
printf("%d\n", v.i);    // 65
printf("%c\n", v.c);    // 'A' (те же байты как символ)
```

### 8.5. Когда использовать

- **Экономия памяти**, когда известно, что используется только одно поле.
- **Низкоуровневые преобразования** типов (например, побитовый доступ к `float`).
- **Тегированные объединения** — структура с полем-тегом и `union` внутри:

```c
typedef struct {
    int type;   // 0 = int, 1 = float
    union {
        int i;
        float f;
    } value;
} Variant;
```

## 9. Структура vs объединение

| Критерий | `struct` | `union` |
|---|---|---|
| Память | Сумма размеров всех полей | Размер максимального поля |
| Одновременное хранение | Все поля сразу | Только одно поле |
| Доступ | Ко всем полям | Только к последнему записанному |
| Применение | Описание объектов | Экономия памяти, преобразования |

**Пример:**
```c
struct S { int i; float f; };   // sizeof = 8 (4 + 4)
union  U { int i; float f; };   // sizeof = 4 (max)
```

## 10. Пример: структура `Student` целиком

```c
#include <stdio.h>
#include <string.h>

typedef struct Student {
    char name[50];
    int age;
    double average;
} Student;

void printStudent(const Student *s) {
    printf("Имя: %s\n", s->name);
    printf("Возраст: %d\n", s->age);
    printf("Средний балл: %.2f\n", s->average);
}

int main(void) {
    Student s;
    strcpy(s.name, "Иван");
    s.age = 18;
    s.average = 4.5;

    printStudent(&s);
    return 0;
}
```

**Вывод:**
```
Имя: Иван
Возраст: 18
Средний балл: 4.50
```

## 11. Ответы на частые вопросы

**1. Что такое `s` в `struct Student s;`?**  
`s` — **имя переменной** (экземпляра структуры). Тип — `struct Student`. В памяти под `s` выделяется место под все поля.

**2. Можно ли присвоить одну структуру другой?**  
Да, если они одного типа: `s1 = s2;` — копирует все поля.

**3. Можно ли сравнить две структуры через `==`?**  
**Нет.** Нужно сравнивать поля по отдельности или через `memcmp`.

**4. Чем `union` отличается от `struct`?**  
В `struct` все поля хранятся **одновременно**, в `union` — **только одно** (все делят одну память).

**5. Что означает `p->age`?**  
Это `(*p).age` — доступ к полю `age` через указатель `p`.

## 12. Итоги лекции

- **Структура** — составной тип, объединяющий поля разных типов.
- **`s` в `struct Student s;`** — имя переменной, а не тип и не поле.
- **Доступ к полям**: `s.age` (переменная), `p->age` (указатель).
- **Передача в функции**: по значению (копия) или по указателю (эффективно).
- **`typedef`** упрощает синтаксис.
- **Объединение** — тип, где все поля делят одну память; хранится только одно значение.
