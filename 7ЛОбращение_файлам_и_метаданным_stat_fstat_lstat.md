## 2. Что такое метаданные

Когда вы работаете с файлом через `fopen` или `open`, вы имеете дело с **содержимым**. Но у файла есть и **служебная информация** — метаданные:

- размер,
- права доступа,
- владелец и группа,
- время создания, изменения, доступа,
- тип (обычный файл, каталог, символьная ссылка, устройство).

Эта информация хранится **отдельно от содержимого** — в структуре файловой системы, которая называется **inode** (index node). Имя файла и inode связаны через **каталог**.

**Важно:** у одного файла может быть **несколько имён** (жёсткие ссылки), но **один inode**. Метаданные хранятся именно в inode, а не в имени.

## 3. Структура `struct stat`

Все три функции заполняют одну и ту же структуру — `struct stat` из `<sys/stat.h>`.

```c
#include <sys/stat.h>

struct stat {
    dev_t     st_dev;      // устройство, на котором файл
    ino_t     st_ino;      // номер inode
    mode_t    st_mode;     // тип и права доступа
    nlink_t   st_nlink;    // число жёстких ссылок
    uid_t     st_uid;      // ID владельца
    gid_t     st_gid;      // ID группы
    off_t     st_size;     // размер в байтах
    time_t    st_atime;    // время последнего доступа
    time_t    st_mtime;    // время последнего изменения
    time_t    st_ctime;    // время последнего изменения inode
    // ... и другие поля (зависят от системы)
};
```

**Основные поля:**

| Поле | Что содержит |
|------|--------------|
| `st_size` | Размер файла в байтах |
| `st_mode` | Тип файла + права доступа |
| `st_nlink` | Сколько имён указывают на этот inode |
| `st_uid`, `st_gid` | Владелец и группа |
| `st_mtime` | Время последнего изменения содержимого |
| `st_atime` | Время последнего чтения |
| `st_ctime` | Время последнего изменения метаданных |
| `st_ino` | Номер inode |

## 4. `stat` — информация по имени

```c
#include <sys/stat.h>

int stat(const char *pathname, struct stat *buf);
```

**Что делает:** заполняет `buf` информацией о файле по пути `pathname`.

**Возвращает:** `0` при успехе, `-1` при ошибке (`errno`).

**Пример:**

```c
#include <stdio.h>
#include <sys/stat.h>

int main(void)
{
    struct stat st;

    if (stat("data.txt", &st) == -1) {
        perror("stat");
        return 1;
    }

    printf("Размер: %ld байт\n", (long)st.st_size);
    printf("Ссылок: %lu\n", (unsigned long)st.st_nlink);
    printf("Inode: %lu\n", (unsigned long)st.st_ino);
    printf("Права: %o\n", st.st_mode & 0777);

    return 0;
}
```

---

## 5. `fstat` — информация по дескриптору

```c
int fstat(int fd, struct stat *buf);
```

**Что делает:** то же самое, но по **открытому дескриптору**.

**Возвращает:** `0` или `-1`.

**Пример:**

```c
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <stdio.h>

int main(void)
{
    int fd = open("data.txt", O_RDONLY);
    if (fd == -1) { perror("open"); return 1; }

    struct stat st;
    if (fstat(fd, &st) == -1) {
        perror("fstat");
        close(fd);
        return 1;
    }

    printf("Размер: %ld\n", (long)st.st_size);
    close(fd);
    return 0;
}
```

**Когда использовать `fstat`:**
- Когда файл уже открыт.
- Когда **важна безопасность** — файл мог быть подменён ссылкой между `open` и `stat`. `fstat` работает с **тем самым** файлом, который открыт.

## 6. `lstat` — информация о ссылке

```c
int lstat(const char *pathname, struct stat *buf);
```

**Что делает:** то же, что `stat`, но если `pathname` — **символическая ссылка**, возвращает информацию **о самой ссылке**, а не о файле, на который она указывает.

**Возвращает:** `0` или `-1`.

**Пример:**

```c
struct stat st;

if (lstat("link.txt", &st) == -1) {
    perror("lstat");
    return 1;
}

if (S_ISLNK(st.st_mode)) {
    printf("Это символическая ссылка\n");
    printf("Размер ссылки: %ld\n", (long)st.st_size);
}
```

**Разница:**

| Функция | Для ссылки |
|---------|-----------|
| `stat` | Информация о **целевом** файле |
| `lstat` | Информация о **самой ссылке** |

## 7. Разбор `st_mode`

Поле `st_mode` содержит **два набора бит**:
1. **Тип файла** — старшие биты.
2. **Права доступа** — младшие 9 бит.

### Тип файла

Проверяется через **макросы** из `<sys/stat.h>`:

| Макрос | Что проверяет |
|--------|---------------|
| `S_ISREG(m)` | Обычный файл |
| `S_ISDIR(m)` | Каталог |
| `S_ISLNK(m)` | Символическая ссылка |
| `S_ISCHR(m)` | Символьное устройство |
| `S_ISBLK(m)` | Блочное устройство |
| `S_ISFIFO(m)` | Канал (FIFO) |
| `S_ISSOCK(m)` | Сокет |

**Пример:**

```c
if (S_ISREG(st.st_mode))
    printf("Обычный файл\n");
else if (S_ISDIR(st.st_mode))
    printf("Каталог\n");
else if (S_ISLNK(st.st_mode))
    printf("Символическая ссылка\n");
```

### Права доступа

Младшие 9 бит — это права для трёх категорий:

| Бит | Что означает |
|-----|--------------|
| `S_IRUSR` | Чтение владельцем |
| `S_IWUSR` | Запись владельцем |
| `S_IXUSR` | Выполнение владельцем |
| `S_IRGRP` | Чтение группой |
| `S_IWGRP` | Запись группой |
| `S_IXGRP` | Выполнение группой |
| `S_IROTH` | Чтение остальными |
| `S_IWOTH` | Запись остальными |
| `S_IXOTH` | Выполнение остальными |

**Проверка:**

```c
if (st.st_mode & S_IRUSR)
    printf("Владелец может читать\n");

if (st.st_mode & S_IWOTH)
    printf("Все могут писать (!)\n");
```

**Вывод в восьмеричном виде:**

```c
printf("Права: %o\n", st.st_mode & 0777);
// например: 644
```

## 8. Форматирование времени

Время хранится как `time_t` — число секунд с 1 января 1970 года.

**Преобразование в читаемый вид:**

```c
#include <time.h>

char buf[64];
struct tm *tm_info;

tm_info = localtime(&st.st_mtime);
strftime(buf, sizeof(buf), "%Y-%m-%d %H:%M:%S", tm_info);
printf("Изменён: %s\n", buf);
```

**Спецификаторы `strftime`:**

| Код | Значение |
|-----|----------|
| `%Y` | Год (4 цифры) |
| `%m` | Месяц (01–12) |
| `%d` | День (01–31) |
| `%H` | Часы (00–23) |
| `%M` | Минуты |
| `%S` | Секунды |

## 9. Полный пример: вывод информации о файле

```c
#include <stdio.h>
#include <sys/stat.h>
#include <time.h>

int main(int argc, char *argv[])
{
    if (argc != 2) {
        fprintf(stderr, "Использование: %s <файл>\n", argv[0]);
        return 1;
    }

    struct stat st;
    if (stat(argv[1], &st) == -1) {
        perror("stat");
        return 1;
    }

    printf("Файл: %s\n", argv[1]);
    printf("Размер: %ld байт\n", (long)st.st_size);
    printf("Inode: %lu\n", (unsigned long)st.st_ino);
    printf("Ссылок: %lu\n", (unsigned long)st.st_nlink);
    printf("Права: %o\n", st.st_mode & 0777);

    printf("Тип: ");
    if (S_ISREG(st.st_mode)) printf("обычный файл\n");
    else if (S_ISDIR(st.st_mode)) printf("каталог\n");
    else if (S_ISLNK(st.st_mode)) printf("символическая ссылка\n");
    else printf("другое\n");

    char buf[64];
    struct tm *tm;
    tm = localtime(&st.st_mtime);
    strftime(buf, sizeof(buf), "%Y-%m-%d %H:%M:%S", tm);
    printf("Изменён: %s\n", buf);

    return 0;
}
```

**Пример работы:**

```
$ ./stat_info data.txt
Файл: data.txt
Размер: 1024 байт
Inode: 1234567
Ссылок: 1
Права: 644
Тип: обычный файл
Изменён: 2026-09-22 14:35:12
```

## 10. Разница между тремя функциями

| Функция | Аргумент | Что возвращает |
|---------|----------|----------------|
| `stat` | Путь | Информацию о **файле** (по ссылке — о цели) |
| `fstat` | Дескриптор | Информацию об **открытом файле** |
| `lstat` | Путь | Информацию о **самой ссылке** |

**Пример с символической ссылкой:**

```
file.txt       — обычный файл
link.txt       — символическая ссылка на file.txt
```

| Вызов | Что покажет `st_size` |
|-------|----------------------|
| `stat("link.txt", &st)` | Размер `file.txt` |
| `lstat("link.txt", &st)` | Размер ссылки (путь, обычно ~5–10 байт) |
| `fstat(fd, &st)` | Размер файла, открытого через `fd` |

## 11. Типичные ошибки

| Ошибка | Что не так | Решение |
|--------|-----------|---------|
| Забыли проверить `-1` | Работа с мусором | `if (stat(...) == -1)` |
| Использование `st_mode` напрямую | Непонятные биты | Использовать макросы `S_IS*` |
| Забыли `&st` | Передаётся значение | `stat(path, &st)` |
| Сравнение `st_mode == 0644` | Не учитывает тип | `(st.st_mode & 0777) == 0644` |
| `%ld` для `st_size` | На разных системах разный размер | Приводить к `long` |
| `stat` вместо `lstat` для ссылок | Получите информацию не о ссылке | Использовать `lstat` |

---

## 12. Итоги

- **Метаданные** хранятся в inode, не в имени.
- **`struct stat`** содержит размер, права, время, тип.
- **`stat`** — по пути, **`fstat`** — по дескриптору, **`lstat`** — по ссылке.
- **`st_mode`** содержит тип и права; проверяются через `S_IS*` и `S_I*`.
- **Время** преобразуется через `localtime` и `strftime`.
- **Всегда проверяйте** возврат `-1`.
