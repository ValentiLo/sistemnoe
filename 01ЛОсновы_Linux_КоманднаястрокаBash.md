## 2. Что такое командная строка

**Командная строка** (shell, терминал) — это интерфейс, в котором вы вводите команды текстом, а система их выполняет.

**Bash** (Bourne Again Shell) — самая популярная оболочка Linux.

**Структура приглашения:**

```
user@hostname:~$
│    │        ││
│    │        │└─ символ приглашения ($ — обычный, # — root)
│    │        └── текущий каталог (~ = домашний)
│    └─────────── имя компьютера
└──────────────── имя пользователя
```

**Пример:**

```
student@ubuntu:~/projects$
```

## 3. Файловая система Linux

**Всё — файл.** Даже устройства, каталоги, сокеты.

**Корень — `/`** (в отличие от Windows, где диски `C:`, `D:`).

**Основные каталоги:**

| Каталог | Что содержит |
|---------|--------------|
| `/` | Корень |
| `/bin` | Основные программы |
| `/etc` | Конфигурации |
| `/home` | Домашние каталоги пользователей |
| `/tmp` | Временные файлы |
| `/var` | Изменяемые данные (логи) |
| `/usr` | Программы и библиотеки |
| `/dev` | Устройства |
| `/proc` | Информация о процессах |

**Пути:**

| Тип | Пример | Что означает |
|-----|--------|--------------|
| **Абсолютный** | `/home/user/file.txt` | От корня `/` |
| **Относительный** | `docs/file.txt` | От текущего каталога |
| **Домашний** | `~/file.txt` | Домашний каталог |
| **Родительский** | `..` | На уровень вверх |
| **Текущий** | `.` | Текущий каталог |

## 4. `ls` — список файлов

```bash
ls [опции] [путь]
```

**Основные опции:**

| Опция | Что делает |
|-------|-----------|
| `-l` | Подробный список |
| `-a` | Показать скрытые (начинаются с `.`) |
| `-h` | Размер в удобном виде (KB, MB) |
| `-t` | Сортировка по времени |
| `-r` | Обратный порядок |
| `-R` | Рекурсивно по подкаталогам |

**Примеры:**

```bash
ls                # файлы в текущем каталоге
ls -la            # подробно + скрытые
ls -lh /var/log   # размеры в удобном виде
ls *.c            # только файлы .c
```

**Пример вывода `ls -l`:**

```
-rw-r--r-- 1 user group 1024 Sep 22 14:35 file.txt
│└┬┘└┬┘└┬┘ │  │    │     │    │           │
│ │  │  │  │  │    │     │    │           └ имя
│ │  │  │  │  │    │     │    └── время
│ │  │  │  │  │    │     └─────── размер
│ │  │  │  │  │    └───────────── группа
│ │  │  │  │  └────────────────── владелец
│ │  │  │  └───────────────────── ссылок
│ │  │  └──────────────────────── права для остальных
│ │  └─────────────────────────── права для группы
│ └────────────────────────────── права для владельца
└──────────────────────────────── тип файла
```

## 5. `cd` — переход по каталогам

```bash
cd [путь]
```

**Примеры:**

| Команда | Что делает |
|---------|-----------|
| `cd /etc` | Перейти в `/etc` |
| `cd ~` | В домашний каталог |
| `cd` | То же самое (без аргумента) |
| `cd ..` | На уровень вверх |
| `cd ../..` | На два уровня вверх |
| `cd -` | Вернуться в предыдущий каталог |
| `cd /home/user/docs` | Абсолютный путь |

**Полезные команды рядом:**

| Команда | Что делает |
|---------|-----------|
| `pwd` | Показать текущий каталог |
| `pushd` / `popd` | Сохранить/восстановить каталог |

## 6. `cat` — вывести содержимое файла

```bash
cat [опции] файл
```

**Примеры:**

```bash
cat file.txt              # вывести содержимое
cat file1.txt file2.txt   # вывести два файла подряд
cat -n file.txt           # с номерами строк
cat > new.txt             # создать файл (Ctrl+D — конец)
cat file1 file2 > all.txt # объединить
```

**Опции:**

| Опция | Что делает |
|-------|-----------|
| `-n` | Нумеровать строки |
| `-b` | Нумеровать непустые строки |
| `-A` | Показать непечатаемые символы |
| `-s` | Сжать пустые строки |

⚠️ **`cat` плохо подходит для больших файлов** — они прокрутятся мгновенно. Используйте `less`.

**Родственные команды:**

| Команда | Что делает |
|---------|-----------|
| `less file` | Постраничный просмотр (q — выход) |
| `more file` | Упрощённый просмотр |
| `head file` | Первые 10 строк |
| `head -n 20 file` | Первые 20 строк |
| `tail file` | Последние 10 строк |
| `tail -f file` | Следить за файлом в реальном времени |
| `tail -n 50 file` | Последние 50 строк |

## 7. `grep` — поиск по содержимому

```bash
grep [опции] шаблон [файл...]
```

**Примеры:**

```bash
grep "error" log.txt          # найти "error" в файле
grep -i "error" log.txt       # без учёта регистра
grep -r "TODO" .              # рекурсивно по каталогу
grep -n "main" main.c         # с номерами строк
grep -v "debug" log.txt       # исключить строки
grep -c "error" log.txt       # количество совпадений
grep -l "error" *.log         # только имена файлов
```

**Основные опции:**

| Опция | Что делает |
|-------|-----------|
| `-i` | Игнорировать регистр |
| `-r` | Рекурсивно |
| `-n` | Номера строк |
| `-v` | Инвертировать (не совпало) |
| `-c` | Только количество |
| `-l` | Только имена файлов |
| `-w` | Слово целиком |
| `-E` | Расширенное регулярное выражение |

**Регулярные выражения:**

| Символ | Что означает |
|--------|--------------|
| `.` | Любой символ |
| `*` | Ноль или больше предыдущего |
| `^` | Начало строки |
| `$` | Конец строки |
| `[abc]` | Любой из символов |
| `[^abc]` | Не из этих символов |
| `\|` | Или (в `-E`) |

**Примеры:**

```bash
grep "^#" config.txt         # строки, начинающиеся с #
grep "log$" file.txt         # строки, заканчивающиеся на "log"
grep -E "err(or|ors)" log    # err или error
```

## 8. `find` — поиск файлов

```bash
find [где] [что]
```

**Примеры:**

```bash
find . -name "*.c"                # все .c в текущем каталоге
find /home -name "*.txt"          # все .txt в /home
find . -type f                    # только файлы
find . -type d                    # только каталоги
find . -size +10M                 # файлы > 10 MB
find . -mtime -7                  # изменённые за 7 дней
find . -name "*.log" -delete      # удалить все .log
find . -name "*.c" -exec grep -l "main" {} \;
```

**Основные опции:**

| Опция | Что делает |
|-------|-----------|
| `-name` | По имени |
| `-iname` | По имени (без регистра) |
| `-type f` | Только файлы |
| `-type d` | Только каталоги |
| `-size` | По размеру |
| `-mtime` | По времени изменения |
| `-user` | По владельцу |
| `-perm` | По правам |
| `-exec` | Выполнить команду |

## 9. Работа с потоками

**Три стандартных потока:**

| Поток | Номер | Что это |
|-------|:-----:|---------|
| stdin | 0 | Ввод |
| stdout | 1 | Вывод |
| stderr | 2 | Ошибки |

**Перенаправления:**

| Синтаксис | Что делает |
|-----------|-----------|
| `>` | Записать в файл (перезаписать) |
| `>>` | Дописать в конец |
| `<` | Читать из файла |
| `2>` | Ошибки в файл |
| `2>&1` | Ошибки туда же, куда вывод |
| `\|` | Конвейер |

**Примеры:**

```bash
ls -l > files.txt              # записать в файл
echo "текст" >> log.txt        # дописать
grep error log.txt > errors.txt
ls *.c | wc -l                 # посчитать .c файлы
cat file.txt | grep "TODO"     # найти TODO
find . -name "*.c" | xargs grep "main"
```

## 11. Шаблоны и подстановки

**Glob-шаблоны (в shell):**

| Шаблон | Что означает |
|--------|--------------|
| `*` | Любая последовательность символов |
| `?` | Один символ |
| `[abc]` | Один из символов |
| `[a-z]` | Диапазон |
| `{a,b,c}` | Любой из вариантов |

**Примеры:**

```bash
ls *.txt              # все .txt
ls file?.c            # file1.c, fileA.c, но не file10.c
ls *.{c,h}            # .c и .h
cp file.{txt,bak}     # копировать в .bak
```

⚠️ **Glob раскрывает shell**, а не сама команда. `grep` и `find` используют **регулярные выражения** — это разные вещи.

## 12. Типичные ошибки

| Ошибка | Что не так | Решение |
|--------|-----------|---------|
| `cd..` без пробела | Не сработает | `cd ..` |
| `ls - l` с пробелом | Опция не распознается | `ls -l` |
| `rm -rf /` | Удалить всё! | Никогда так не делать |
| `grep` без кавычек | Шаблон раскроет shell | `grep "текст"` |
| Забыли `-r` в `grep` | Не ищет в подкаталогах | `grep -r` |
| `>` вместо `>>` | Затрёт файл | `>>` для дозаписи |
| Путь с пробелами | Разобьётся на аргументы | В кавычках: `"my file.txt"` |

## 13. Итоги

- **Bash** — главная оболочка Linux.
- **Файловая система** — всё от корня `/`.
- **`ls`** — список файлов.
- **`cd`** — переход по каталогам.
- **`cat`** — вывод содержимого (для больших файлов — `less`).
- **`grep`** — поиск по содержимому (регулярные выражения).
- **`find`** — поиск файлов по имени, размеру, времени.
- **Перенаправления** — `>`, `>>`, `|`.
