# Инструкция: запуск программ на C в MSYS2 MINGW64

Пошаговое руководство для тех, кто только начинает.

---

## 1. Что понадобится

- **MSYS2 MINGW64** — терминал (ярлык в меню «Пуск»).
- **Компилятор GCC** — установлен в MSYS2.
- **Текстовый редактор** — `nano` (встроенный) или VS Code.

---

## 2. Открыть MSYS2 MINGW64

1. Нажмите **Win**.
2. Введите **MSYS2 MINGW64**.
3. Откройте приложение.

Появится окно с приглашением:

```
user@hostname MINGW64 ~
$
```

Знак `~` означает **домашнюю папку MSYS2** — `C:\msys64\home\<имя>`.

---

## 3. Создать папку для проектов (один раз)

```bash
mkdir -p ~/projects
cd ~/projects
```

**Разбор:**
- `mkdir -p` — создать папку (и все вложенные).
- `cd` — перейти в неё.
- `~/projects` — папка `projects` в домашней папке MSYS2.

**Проверить, где мы:**

```bash
pwd
```

**Вывод:**

```
/home/user/projects
```

---

## 4. Создать файл с программой

### Способ А. Через `nano` (встроенный)

```bash
nano hello.c
```

Откроется редактор. Введите код:

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

**Сохранить:**
1. `Ctrl + O` — записать.
2. `Enter` — подтвердить имя.
3. `Ctrl + X` — выйти.

### Способ Б. Через VS Code

```bash
code hello.c
```

Если команда `code` не работает — откройте VS Code вручную и создайте файл в папке `~/projects`.

---

## 5. Скомпилировать программу

```bash
gcc -Wall -Wextra -g -o hello hello.c
```

**Разбор флагов:**

| Флаг | Что означает |
|------|--------------|
| `-Wall` | Все предупреждения |
| `-Wextra` | Дополнительные предупреждения |
| `-g` | Отладочная информация (для GDB) |
| `-o hello` | Имя выходного файла |
| `hello.c` | Исходный файл |

**Если ошибок нет** — команда завершится **молча**, появится новое приглашение `$`. Это нормально.

**Проверить, что файл создался:**

```bash
ls -la hello*
```

**Вывод:**

```
-rwxr-xr-x 1 user user 50000 hello
-rw-r--r-- 1 user user   100 hello.c
```

Файл `hello` (без расширения) — это **исполняемая программа**.

---

## 6. Запустить программу

```bash
./hello
```

⚠️ **Точка и слеш обязательны** — они означают «запустить из текущей папки».

**Вывод:**

```
Hello, World!
```

---

## 7. Полный цикл (кратко)

```bash
cd ~/projects          # 1. Перейти в папку
nano hello.c           # 2. Создать файл
gcc -Wall -Wextra -g -o hello hello.c   # 3. Скомпилировать
./hello                # 4. Запустить
```

---

## 8. Если программа с вводом

Например, `main.c`:

```c
#include <stdio.h>

int main(void)
{
    int x;
    printf("Введите число: ");
    scanf("%d", &x);
    printf("Вы ввели: %d\n", x);
    return 0;
}
```

**Компиляция и запуск:**

```bash
gcc -Wall -Wextra -g -o app main.c
./app
```

**Пример:**

```
Введите число: 42
Вы ввели: 42
```

---

## 9. Если программа использует математику

```c
#include <math.h>
```

**Компиляция:**

```bash
gcc -Wall -Wextra -g -o app main.c -lm
```

⚠️ **`-lm`** — подключает математическую библиотеку. Без него — ошибка `undefined reference to 'sqrt'`.

---

## 10. Если программа использует потоки

```c
#include <pthread.h>
```

**Компиляция:**

```bash
gcc -Wall -Wextra -g -o app main.c -pthread
```

⚠️ **`-pthread`** — подключает библиотеку потоков.

---

## 11. Частые ошибки

| Ошибка | Что не так | Решение |
|--------|-----------|---------|
| `gcc: command not found` | Компилятор не установлен | `pacman -S mingw-w64-x86_64-gcc` |
| `hello.c: No such file or directory` | Файл не в той папке | `pwd` + `ls` |
| `./hello: No such file` | Не скомпилировалось | Прочитать ошибки `gcc` |
| `Permission denied` | Нет прав на запуск | `chmod +x hello` |
| `undefined reference to 'sqrt'` | Нужен `-lm` | Добавить флаг |
| Ошибки `-Wall` | Предупреждения | Исправить код |
| `Segmentation fault` | Ошибка в программе | Использовать GDB |

## 12. Полезные команды

| Команда | Что делает |
|---------|-----------|
| `pwd` | Показать текущую папку |
| `ls` | Список файлов |
| `ls -la` | Подробный список |
| `cd папка` | Перейти в папку |
| `cd ..` | На уровень вверх |
| `cd ~` | В домашнюю папку |
| `mkdir папка` | Создать папку |
| `rm файл` | Удалить файл |
| `cat файл` | Показать содержимое |
| `nano файл` | Редактировать |
| `clear` | Очистить экран |

---

## 13. Где лежат файлы

Файлы, созданные в MSYS2 MINGW64 в домашней папке `~`, физически лежат здесь:

```
C:\msys64\home\<имя_пользователя>\
```

Например, `~/projects/hello.c` — это:

```
C:\msys64\home\<имя>\projects\hello.c
```

**Как открыть в Проводнике Windows:**

1. Откройте Проводник.
2. В адресной строке введите: `C:\msys64\home\<имя>`.
3. Нажмите Enter.


**С математикой:**


**С потоками:**


## 15. Что дальше

- **Отладка:** `gdb ./hello`
- **Проверка утечек:** `valgrind --leak-check=full ./hello` (если доступно)
- **Сборка проектов:** `make` + `Makefile`
- **Работа в VS Code:** открыть папку `~/projects` и настроить `tasks.json`

---

**Главное правило:** после компиляции всегда запускайте через `./имя` — точка и слеш обязательны.
