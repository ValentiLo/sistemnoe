# Сумма всех элементов матрицы 3×3

**Условие:** дана матрица 3×3. Найти сумму всех её элементов.

---

## 💻 Код

```c
#include <stdio.h>

#define ROWS 3
#define COLUMNS 3

int main(void)
{
    int a[ROWS][COLUMNS];
    int sum = 0;

    // 1. Чтение матрицы
    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLUMNS; j++) {
            scanf("%d", &a[i][j]);
        }
    }

    // 2. Суммирование всех элементов
    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLUMNS; j++) {
            sum += a[i][j];
        }
    }

    // 3. Вывод суммы
    printf("%d\n", sum);

    return 0;
}
```

---

## 🔍 Пояснение

### 1. Инициализация суммы

```c
int sum = 0;
```

⚠️ **Обязательно `= 0`** — иначе там будет мусор, и сумма получится неверной.

### 2. Двойной цикл

```c
for (int i = 0; i < ROWS; i++) {
    for (int j = 0; j < COLUMNS; j++) {
        sum += a[i][j];
    }
}
```

- **Внешний цикл** — по строкам.
- **Внутренний цикл** — по столбцам.
- **`sum += a[i][j]`** — прибавляем текущий элемент к сумме.

Это то же самое, что:

```c
sum = sum + a[i][j];
```

### 3. Порядок обхода

```
i=0: a[0][0] + a[0][1] + a[0][2]
i=1: a[1][0] + a[1][1] + a[1][2]
i=2: a[2][0] + a[2][1] + a[2][2]
```

Все 9 элементов суммируются.

---

## 📌 Пример работы

**Ввод:**
```
1 2 3
4 5 6
7 8 9
```

**Расчёт:**
- `1 + 2 + 3 = 6`
- `4 + 5 + 6 = 15`
- `7 + 8 + 9 = 24`
- Итого: `6 + 15 + 24 = 45`

**Вывод:**
```
45
```

---

**Ввод:**
```
-1 2 -3
4 -5 6
-7 8 -9
```

**Расчёт:**
- `-1 + 2 - 3 = -2`
- `4 - 5 + 6 = 5`
- `-7 + 8 - 9 = -8`
- Итого: `-2 + 5 - 8 = -5`

**Вывод:**
```
-5
```

## 💡 Варианты

### 1. Суммирование **в одном цикле** (через указатель)

Так как матрица лежит в памяти непрерывно:

```c
int *p = &a[0][0];
for (int k = 0; k < ROWS * COLUMNS; k++) {
    sum += p[k];
}
```

**Плюс:** короче.
**Минус:** менее наглядно.

### 2. Суммирование **во время чтения**

Можно не хранить матрицу, а сразу прибавлять:

```c
int x, sum = 0;
for (int i = 0; i < ROWS * COLUMNS; i++) {
    scanf("%d", &x);
    sum += x;
}
```

**Плюс:** экономит память.
**Минус:** нельзя потом обратиться к отдельным элементам.

Для задачи «найти сумму» — **этот вариант оптимален**.

### 3. Сумма по строкам

Если нужна **сумма каждой строки** отдельно:

```c
for (int i = 0; i < ROWS; i++) {
    int row_sum = 0;
    for (int j = 0; j < COLUMNS; j++) {
        row_sum += a[i][j];
    }
    printf("Сумма строки %d: %d\n", i, row_sum);
}
```

---

## 📊 Сравнение вариантов

| Вариант | Память | Наглядность | Когда использовать |
|---------|:------:|:-----------:|-------------------|
| Двойной цикл | `N×M` | ✅ Высокая | Универсальный |
| Один цикл + указатель | `N×M` | ⚠️ Средняя | Когда важна краткость |
| Без хранения матрицы | `O(1)` | ✅ Высокая | Когда нужна только сумма |
| По строкам | `N×M` | ✅ Высокая | Когда нужны суммы строк |

---

## ⚠️ Частые ошибки

| Ошибка | Что не так | Правильно |
|--------|-----------|-----------|
| `int sum;` (без `= 0`) | Мусор в сумме | `int sum = 0;` |
| `sum += a[i][i];` | Суммирует только диагональ | `sum += a[i][j];` |
| `for (j = 0; j <= COLUMNS; j++)` | Выход за границы | `j < COLUMNS` |
| `sum = a[i][j];` | Присваивание, а не сложение | `sum += a[i][j];` |
| Печать внутри цикла | Выведет 9 промежуточных сумм | Печать **после** циклов |

## 🎯 Готовый ответ для сдачи

```c
#include <stdio.h>

#define ROWS 3
#define COLUMNS 3

int main(void)
{
    int a[ROWS][COLUMNS];
    int sum = 0;

    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLUMNS; j++) {
            scanf("%d", &a[i][j]);
        }
    }

    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLUMNS; j++) {
            sum += a[i][j];
        }
    }

    printf("%d\n", sum);

    return 0;
}
```

**Что делает:**
1. Читает 9 чисел в матрицу 3×3.
2. Проходит по всем элементам двойным циклом.
3. Накапливает сумму в переменной `sum`.
4. Выводит результат.

**Пример:**
- Ввод: `1 2 3 4 5 6 7 8 9`
- Вывод: `45`

## 📌 Итог

**Сумма всех элементов матрицы:**

```c
int sum = 0;
for (int i = 0; i < ROWS; i++)
    for (int j = 0; j < COLUMNS; j++)
        sum += a[i][j];
```

**Ключевые моменты:**
- **`sum = 0`** — обязательно обнулить.
- **Двойной цикл** — обход всех элементов.
- **`+=`** — накопление суммы.
- **Печать после циклов** — иначе получите промежуточные результаты.
