# Решение: увеличить `a[1][2]` в 10 раз

**Условие:** дана матрица **3×3**. Нужно увеличить элемент `a[1][2]` в 10 раз и напечатать полученную матрицу.

---

## 💻 Код

```c
#include <stdio.h>

#define ROWS 3
#define COLUMNS 3

int main(void)
{
    int a[ROWS][COLUMNS];

    // 1. Чтение массива
    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLUMNS; j++) {
            scanf("%d", &a[i][j]);
        }
    }

    // 2. Увеличиваем a[1][2] в 10 раз
    a[1][2] = a[1][2] * 10;

    // 3. Печать массива
    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLUMNS; j++) {
            printf("%d ", a[i][j]);
        }
        printf("\n");
    }

    return 0;
}
```

---

## 🔍 Что такое `a[1][2]`

**Индексация с нуля:**

| | столбец 0 | столбец 1 | **столбец 2** |
|---|:---:|:---:|:---:|
| строка 0 | `a[0][0]` | `a[0][1]` | `a[0][2]` |
| **строка 1** | `a[1][0]` | `a[1][1]` | **`a[1][2]`** |
| строка 2 | `a[2][0]` | `a[2][1]` | `a[2][2]` |

- **`a[1]`** — **вторая строка** (индекс 1).
- **`a[1][2]`** — **третий элемент** этой строки (индекс 2).

⚠️ **Не путать:** `a[1][2]` — это **не** «строка 1, столбец 2» в человеческом понимании (где счёт с 1), а именно индексы **1 и 2**.

---

## 📌 Пример работы

**Ввод:**
```
1 2 3
4 5 6
7 8 9
```

**Исходная матрица:**
```
1 2 3
4 5 6
7 8 9
```

**Элемент `a[1][2]` = 6.** Увеличиваем в 10 раз → `60`.

**Вывод:**
```
1 2 3
4 5 60
7 8 9
```

**Ввод:**
```
10 20 30
40 50 60
70 80 90
```

**Элемент `a[1][2]` = 60.** Увеличиваем → `600`.

**Вывод:**
```
10 20 30

70 80 90
```

## 💡 Ключевые моменты

### 1. Изменение элемента

```c
a[1][2] = a[1][2] * 10;
```

Можно записать короче:

```c
a[1][2] *= 10;
```

Обе записи эквивалентны — умножение на 10 «на месте».

### 2. Где менять — **после чтения**, но **до печати**

Порядок важен:
1. **Сначала** читаем все элементы.
2. **Потом** изменяем нужный.
3. **В конце** печатаем.

Если изменить **до** чтения — значение перезапишется при вводе. Если **после** печати — изменения не попадут в вывод.

### 3. Размер матрицы — **3×3**

В вашем шаблоне было `ROWS 3`, `COLUMNS 4`. Для этой задачи нужно **3×3**:

```c
#define ROWS 3
#define COLUMNS 3
```

⚠️ Если оставить `COLUMNS 4`, программа будет читать 12 чисел вместо 9 — это неверно.

## 🎯 Готовый ответ для сдачи

```c
#include <stdio.h>

#define ROWS 3
#define COLUMNS 3

int main(void)
{
    int a[ROWS][COLUMNS];

    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLUMNS; j++) {
            scanf("%d", &a[i][j]);
        }
    }

    a[1][2] = a[1][2] * 10;

    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLUMNS; j++) {
            printf("%d ", a[i][j]);
        }
        printf("\n");
    }

    return 0;
}
```

**Что делает:**
1. Читает 9 чисел в матрицу 3×3.
2. Умножает элемент `a[1][2]` (вторая строка, третий столбец) на 10.
3. Печатает матрицу с изменённым элементом.

**Пример:**
- Ввод: `1 2 3 4 5 6 7 8 9`
- Вывод:
  ```
  1 2 3 
  4 5 60 
  7 8 9 
  ```

---

## ⚠️ Частая ошибка

Если по ошибке написать:

```c
a[2][1] = a[2][1] * 10;   // ❌ не тот элемент
```

Это **третий столбец** (индекс 2) **второй строки** (индекс 1), а `a[2][1]` — **вторая строка, третий столбец**. Индексы **не** симметричны.

| Запись | Что означает |
|--------|--------------|
| `a[1][2]` | строка 1, столбец 2 |
| `a[2][1]` | строка 2, столбец 1 |

**Разные элементы!** Внимательно с порядком индексов.

---

## 📌 Итог

**Изменение одного элемента матрицы:**

```c
a[i][j] *= 10;
```

**Место в коде:** после чтения, до печати.

**Ключевое правило:** `a[строка][столбец]` — первый индекс — строка, второй — столбец.

**Для `a[1][2]`** — это **вторая строка, третий столбец** (индексы с нуля). ✅
