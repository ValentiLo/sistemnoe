# Лекция: Структуры хранения информации о файле. Функции и системные вызовы для работы с файлами

**Для новичков — с полного нуля, со схемами и примерами**

---

## Часть 1. Что такое файл и зачем о нём что-то знать

### 1.1. Файл с точки зрения программы

Представьте, что вы работаете в библиотеке. Есть **книги** (файлы) и **каталог карточек** (метаданные), где записано:
- название книги,
- автор,
- год издания,
- количество страниц,
- где она лежит.

Когда вы хотите взять книгу, вы:
1. Смотрите в каталог — **какая это книга, есть ли она**.
2. Берёте её с полки — **открываете**.
3. Читаете — **читаете**.
4. Кладёте обратно — **закрываете**.

С файлами в программе **всё точно так же**. Только вместо рук — функции, а вместо полок — диск.

---

### 1.2. Что хранится о файле

У каждого файла есть **имя** (например, `data.txt`) и **содержимое** (то, что внутри). Но кроме этого — **метаданные**, то есть «данные о данных»:

| Метаданные | Пример | Зачем нужно |
|---|---|---|
| Размер | 348 байт | Понять, сколько читать |
| Тип | обычный файл / каталог | Понять, как обрабатывать |
| Права доступа | чтение, запись, выполнение | Проверить, можно ли открыть |
| Владелец | пользователь `ivan` | Кто создал |
| Время создания/изменения | 29 сентября 2026, 14:30 | Отследить изменения |
| Номер inode | 123456 | Уникальный идентификатор |

Эти метаданные хранятся в **специальной структуре** — `struct stat`. О ней — ниже.

## Часть 2. Файловый дескриптор — «пропуск» к файлу

### 2.1. Аналогия

Представьте **гардероб** в театре. Вы сдаёте куртку — вам дают **номерок** (например, № 5). По этому номерку вы потом получаете куртку обратно.

**Файловый дескриптор (file descriptor)** — это такой **номерок**. Когда программа открывает файл, ядро ОС выдаёт ей **целое число**. Через это число программа потом обращается к файлу: читает, пишет, закрывает.

### 2.2. Схема

```
Программа                Ядро ОС
   │                        │
   │  open("data.txt")      │
   │ ─────────────────────► │
   │                        │  находит файл, проверяет права,
   │                        │  создаёт запись в таблице
   │ ◄───────────────────── │
   │  fd = 3                │
   │                        │
   │  read(3, buf, 100)     │
   │ ─────────────────────► │  читает из файла №3
   │ ◄───────────────────── │
   │  100 байт              │
```

### 2.3. Три волшебных числа: 0, 1, 2

Когда программа **только запустилась**, у неё уже есть **три открытых файла**:

| Дескриптор | Имя | Что это |
|---|---|---|
| **0** | `stdin` | Ввод (клавиатура) |
| **1** | `stdout` | Вывод (экран) |
| **2** | `stderr` | Ошибки (экран) |

**Пример:** когда вы пишете `printf("Hello")`, это на самом деле **запись в дескриптор 1**.

Когда вы открываете новый файл, он получает **следующий свободный номер** — обычно 3, потом 4, 5 и т.д.

## Часть 3. Структура `stat` — «паспорт» файла

### 3.1. Что это

`struct stat` — это **структура** (набор полей), в которой хранится **вся информация о файле**, кроме его содержимого.

### 3.2. Как получить

Есть **три функции**:

```c
#include <sys/stat.h>

int stat(const char *path, struct stat *buf);    // по имени файла
int lstat(const char *path, struct stat *buf);   // для символьных ссылок
int fstat(int fd, struct stat *buf);             // по дескриптору
```

**Разница:**

| Функция | Что делает | Когда использовать |
|---|---|---|
| `stat` | Информация о файле по пути | Обычный случай |
| `lstat` | Если файл — **символьная ссылка**, вернёт информацию **о ссылке**, а не о файле | Работа со ссылками |
| `fstat` | Информация по **открытому дескриптору** | Когда файл уже открыт |

### 3.3. Схема работы `stat`

```
struct stat st;                // объявили переменную
stat("data.txt", &st);         // заполнили её
        │
        ▼
┌─────────────────────────────┐
│ st.st_size   = 348          │ ← размер файла
│ st.st_mode   = 0100644      │ ← тип + права
│ st.st_uid    = 1000         │ ← владелец
│ st.st_mtime  = 1727000000   │ ← время изменения
│ ...                         │
└─────────────────────────────┘
```

### 3.4. Основные поля `struct stat`

```c
struct stat {
    dev_t     st_dev;      // устройство
    ino_t     st_ino;      // номер inode
    mode_t    st_mode;     // тип + права доступа  ← самое важное
    nlink_t   st_nlink;    // количество ссылок
    uid_t     st_uid;      // ID владельца
    gid_t     st_gid;      // ID группы
    off_t     st_size;     // размер в байтах     ← самое важное
    time_t    st_atime;    // время доступа
    time_t    st_mtime;    // время изменения     ← самое важное
    time_t    st_ctime;    // время изменения inode
};
```

**Для новичка достаточно запомнить три поля:**
- `st_size` — размер.
- `st_mode` — тип и права.
- `st_mtime` — время изменения.

---

### 3.5. Поле `st_mode` — «магическое» число

`st_mode` — это **не просто число**, а **упакованная информация**:

```
st_mode (16 бит)
┌──────────────┬───────────────────────┐
│  Тип файла   │   Права доступа       │
│  (4 бита)    │   (12 бит)            │
└──────────────┴───────────────────────┘
```

**Тип файла** (старшие биты):

| Константа | Что означает |
|---|---|
| `S_IFREG` | обычный файл |
| `S_IFDIR` | каталог |
| `S_IFLNK` | символьная ссылка |
| `S_IFBLK` | блочное устройство |
| `S_IFCHR` | символьное устройство |
| `S_IFIFO` | именованный канал |
| `S_IFSOCK` | сокет |

**Права доступа** (младшие биты):

```
rwx rwx rwx
 │   │   └── для остальных
 │   └────── для группы
 └────────── для владельца
```

| Бит | Значение |
|---|---|
| `S_IRUSR` | чтение для владельца |
| `S_IWUSR` | запись для владельца |
| `S_IXUSR` | выполнение для владельца |
| `S_IRGRP` | чтение для группы |
| ... | и так далее |

### 3.6. Как не запутаться: макросы

Вместо того чтобы вручную работать с битами, используйте **макросы**:

```c
S_ISREG(mode)   // это обычный файл?
S_ISDIR(mode)   // это каталог?
S_ISLNK(mode)   // это ссылка?
S_ISCHR(mode)   // символьное устройство?
S_ISBLK(mode)   // блочное устройство?
S_ISFIFO(mode)  // канал?
S_ISSOCK(mode)  // сокет?
```

---

### 3.7. Пример: узнать информацию о файле

```c
#include <stdio.h>
#include <sys/stat.h>

int main(void) {
    struct stat st;
    if (stat("data.txt", &st) == -1) {
        perror("stat");
        return 1;
    }

    printf("Размер: %ld байт\n", (long)st.st_size);
    printf("Тип: %s\n",
           S_ISDIR(st.st_mode) ? "каталог" :
           S_ISREG(st.st_mode) ? "обычный файл" :
           "другое");

    return 0;
}
```

**Пошагово:**
1. Объявляем переменную `st` типа `struct stat`.
2. Вызываем `stat("data.txt", &st)` — заполняем её.
3. Проверяем результат: если `-1` — ошибка.
4. Читаем поля: `st.st_size`, `st.st_mode`.
5. Выводим на экран.

## Часть 4. Системные вызовы для работы с файлами

### 4.1. Схема жизненного цикла файла

```
open()  ──►  read() / write()  ──►  close()
  │              │                     │
  │              │                     │
открыть       читать/писать         закрыть
файл          данные                файл
```

---

### 4.2. `open` — открыть файл

```c
#include <fcntl.h>

int open(const char *filename, int flags, mode_t mode);
```

**Возвращает:** дескриптор (≥ 0) или `-1` при ошибке.

**Флаги** (можно комбинировать через `|`):

| Флаг | Значение |
|---|---|
| `O_RDONLY` | только чтение |
| `O_WRONLY` | только запись |
| `O_RDWR` | чтение и запись |
| `O_CREAT` | создать файл, если нет |
| `O_TRUNC` | обрезать до нуля |
| `O_APPEND` | писать в конец |
| `O_EXCL` | ошибка, если файл есть (с `O_CREAT`) |

**Пример:**

```c
int fd = open("data.txt", O_RDONLY);
if (fd == -1) {
    perror("open");
    return 1;
}
```

**Что произошло:**
- Ядро нашло файл `data.txt`.
- Проверило права.
- Создало запись в таблице.
- Вернуло дескриптор (например, 3).

---

### 4.3. `read` — прочитать данные

```c
#include <unistd.h>

ssize_t read(int fd, void *buf, size_t count);
```

**Аргументы:**
- `fd` — дескриптор.
- `buf` — буфер (куда читать).
- `count` — сколько байт.

**Возвращает:**
- число прочитанных байт,
- `0` — конец файла,
- `-1` — ошибка.

**Пример:**

```c
char buf[256];
ssize_t n = read(fd, buf, sizeof(buf));
```

**Схема:**
```
Файл: [H][e][l][l][o][\0]
        │
        ▼ read(fd, buf, 256)
Буфер: [H][e][l][l][o][\0]
n = 5
```

---

### 4.4. `write` — записать данные

```c
ssize_t write(int fd, const void *buf, size_t count);
```

**Пример:**

```c
const char *msg = "Hello";
write(1, msg, 5);   // запись в stdout (дескриптор 1)
```

**Схема:**
```
Буфер: [H][e][l][l][o]
        │
        ▼ write(1, buf, 5)
Экран: Hello
```

---

### 4.5. `close` — закрыть файл

```c
int close(int fd);
```

**Возвращает:** `0` — успех, `-1` — ошибка.

**Зачем:** освобождает дескриптор. Если не закрыть — дескрипторы **исчерпаются**, и новые `open` начнут падать с ошибкой.

---

### 4.6. `lseek` — переместить позицию

```c
off_t lseek(int fd, off_t offset, int origin);
```

**origin** (откуда считать):

| Значение | Константа | Что означает |
|---|---|---|
| 0 | `SEEK_SET` | от начала |
| 1 | `SEEK_CUR` | от текущей позиции |
| 2 | `SEEK_END` | от конца |

**Примеры:**
```c
lseek(fd, 0, SEEK_SET);    // в начало
lseek(fd, 0, SEEK_END);    // в конец
lseek(fd, -10, SEEK_CUR);  // на 10 байт назад
```

**Схема:**
```
Файл: [A][B][C][D][E][F]
        ▲
        позиция после open = 0

lseek(fd, 3, SEEK_SET);
Файл: [A][B][C][D][E][F]
                    ▲
                    позиция = 3
```

## Часть 5. Полный пример: копирование файла

```c
#include <fcntl.h>
#include <unistd.h>
#include <stdio.h>

int main(void) {
    // 1. Открываем исходный файл
    int src = open("input.txt", O_RDONLY);
    if (src == -1) {
        perror("open input");
        return 1;
    }

    // 2. Открываем файл для записи (создаём, если нет)
    int dst = open("output.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
    if (dst == -1) {
        perror("open output");
        close(src);
        return 1;
    }

    // 3. Читаем блоками и пишем
    char buf[1024];
    ssize_t n;
    while ((n = read(src, buf, sizeof(buf))) > 0) {
        write(dst, buf, n);
    }

    // 4. Закрываем
    close(src);
    close(dst);

    printf("Готово\n");
    return 0;
}
```

**Пошагово:**
1. `open` — открыли `input.txt` для чтения.
2. `open` — открыли `output.txt` для записи (создать, обрезать, права 0644).
3. Цикл: читаем до 1024 байт → пишем столько же.
4. `close` — закрыли оба.

**Что даёт `0644`:**
```
0 6 4 4
  │ │ └── остальные: чтение
  │ └──── группа: чтение
  └────── владелец: чтение + запись
```

## Часть 6. Низкоуровневый и высокоуровневый ввод-вывод

### 6.1. Два подхода

| Низкоуровневый | Высокоуровневый |
|---|---|
| `open`, `read`, `write`, `close` | `fopen`, `fread`, `fwrite`, `fclose` |
| `int fd` | `FILE *` |
| POSIX (Unix/Linux) | Стандарт C (везде) |
| Без буферизации | С буферизацией |

### 6.2. Что такое буферизация

**Без буфера** (низкоуровневый): каждое `read`/`write` = **обращение к диску**. Это медленно.

**С буфером** (высокоуровневый): данные копятся в **буфере в памяти**, а на диск сбрасываются блоками. Это быстрее.

**Схема:**
```
Низкоуровневый:  Программа ──► Диск (каждый раз)
Высокоуровневый: Программа ──► Буфер ──► Диск (пачками)
```

### 6.3. Сравнение на примере

**Низкоуровневый:**
```c
int fd = open("file.txt", O_RDONLY);
char c;
while (read(fd, &c, 1) == 1) {
    putchar(c);
}
close(fd);
```
→ **1000 обращений к диску** на 1000 байт.

**Высокоуровневый:**
```c
FILE *f = fopen("file.txt", "r");
char c;
while ((c = fgetc(f)) != EOF) {
    putchar(c);
}
fclose(f);
```
→ **Несколько обращений к диску**, остальное — из буфера.

## Часть 7. Структура `FILE` — «чёрный ящик»

### 7.1. Что это

Когда вы пишете `FILE *f = fopen(...)`, вы получаете **указатель на структуру `FILE`**. Внутри неё:
- файловый дескриптор,
- буфер,
- позиция в файле,
- флаги (ошибка, конец файла),
- режим буферизации.

### 7.2. Почему «чёрный ящик»

Стандарт C **не определяет** внутреннее устройство `FILE`. Это значит, что **нельзя** писать `f->buffer` — это неопределённое поведение. Работать с `FILE` можно **только через функции**: `fopen`, `fread`, `fwrite`, `fclose`, `fseek` и т.д.

**Аналогия:** вы пользуетесь телевизором через пульт, не залезая внутрь с отвёрткой. Так же и с `FILE` — только через «пульт» (функции).

```
│                   ПРОГРАММА                          │

              │                        │
   Низкоуровневый              Высокоуровневый

              │                        │
              ▼                        ▼
      int fd = open()           FILE *f = fopen()

              │                        │
              ▼                        ▼
        ┌─────────────────────────────────┐
        │         ЯДРО ОС                 │
        │  (таблица дескрипторов, inode)  │
        └─────────────────────────────────┘
                       │
                       ▼
                  ┌──────────┐
                  │   ДИСК   │
                  └──────────┘
```
