# Шпаргалка: struct, union, typedef в C

Компактный справочник для быстрого повторения.

---

## 🔹 struct — объединение полей

**Объявление:**

```c
struct Student {
    char name[50];
    int age;
    double average;
};
```

- Каждое поле занимает **своё место** в памяти.
- Размер = **сумма полей + выравнивание**.
- После `}` **обязательна `;`**.

**Создание переменных:**

```c
struct Student s1;              // одна
struct Student s2, s3;          // несколько
struct Student group[30];       // массив
```

**Инициализация:**

```c
// По порядку
struct Student s = {"Иванов", 18, 4.5};

// По именам (надёжнее)
struct Student s = {
    .name = "Иванов",
    .age = 18,
    .average = 4.5
};
```

**Доступ к полям:**

```c
s.age = 19;
strcpy(s.name, "Петров");
printf("%s\n", s.name);
```

## 🔹 Указатели на структуры

**Оператор `->`** заменяет `(*p).field`:

```c
struct Student s = {"Иванов", 18, 4.5};
struct Student *p = &s;

p->age = 19;              // то же, что (*p).age = 19
printf("%s\n", p->name);  // то же, что (*p).name
```

**Передача в функцию — по указателю:**

```c
void print_student(const struct Student *s) {
    printf("%s, %d\n", s->name, s->age);
}

print_student(&s);   // передаём адрес
```

⚠️ Через `const` защищаем от изменения.

## 🔹 Массивы структур

```c
struct Student group[3] = {
    {"Иванов",  18, 4.5},
    {"Петров",  19, 3.8},
    {"Сидоров", 18, 4.9}
};

for (int i = 0; i < 3; i++) {
    printf("%s — %.2f\n", group[i].name, group[i].average);
}
```

## 🔹 union — одна память на всех

**Объявление:**

```c
union Value {
    int i;
    float f;
    char c;
};
```

- Все поля **делят одну память**.
- Размер = **максимум из полей**.
- В каждый момент хранится **только одно** значение.

**Использование:**

```c
union Value v;
v.i = 42;
printf("%d\n", v.i);   // 42
// v.f и v.c — мусор, потому что их не записывали
```

**Размер:**

```c
printf("%zu\n", sizeof(union Value));   // 4 (размер int/float)
```

---

## 🔹 struct vs union

| Критерий | `struct` | `union` |
|----------|----------|---------|
| Память | Каждое поле — своё | Все делят одно |
| Размер | Сумма полей + выравнивание | Максимум из полей |
| Одновременный доступ | Ко всем полям | Только к одному |
| Применение | Записи, объекты | Варианты, экономия |

## 🔹 typedef — новое имя типа

**Для структуры:**

```c
typedef struct Student {
    char name[50];
    int age;
} Student;

Student s;    // без слова struct
```

**Для union:**

```c
typedef union Value {
    int i;
    float f;
} Value;

Value v;
```

**Для базовых типов:**

```c
typedef unsigned int uint;
typedef int *IntPtr;
typedef int Matrix[3][3];
```

⚠️ `typedef` **не создаёт новый тип**, а даёт **синоним**. Компилятор видит исходный тип.

## 🔹 Выравнивание (padding)

Компилятор может вставлять **пустые байты** между полями:

```c
struct A {
    char c;    // 1 байт
    int i;     // 4 байта, но с выравниванием
};
printf("%zu\n", sizeof(struct A));   // часто 8, а не 5
```

**Правило:** располагайте поля **от большего к меньшему**, если важна экономия:

```c
struct B {
    int i;     // 4
    char c;    // 1 + 3 выравнивания
};              // 8 — то же, но int идёт первым
```

## 🔹 Анонимные структуры и union

**Внутри структуры:**

```c
struct Variant {
    int type;    // 0 = int, 1 = float
    union {
        int i;
        float f;
    } value;
};

struct Variant v;
v.type = 0;
v.value.i = 42;
```

**Анонимный union (C11):**

```c
struct Variant {
    int type;
    union {
        int i;
        float f;
    };    // без имени
};

v.i = 42;    // доступ напрямую
```

## 🔹 Вложенные структуры

```c
struct Point {
    int x, y;
};

struct Rectangle {
    struct Point top_left;
    struct Point bottom_right;
};

struct Rectangle r = {{0, 0}, {10, 10}};
printf("%d\n", r.top_left.x);    // 0
```

## 🔹 Сравнение структур

⚠️ `struct` **нельзя** сравнивать через `==`. Нужно сравнивать **поля**:

```c
if (a.age == b.age && strcmp(a.name, b.name) == 0) { ... }
```

Или через `memcmp` (осторожно с выравниванием):

```c
if (memcmp(&a, &b, sizeof(struct Student)) == 0) { ... }
```

---

## 🔹 Копирование структур

**Присваивание работает:**

```c
struct Student a = {"Иванов", 18, 4.5};
struct Student b = a;    // копирует все поля
```

⚠️ Если внутри структуры есть **указатели**, копируются **сами адреса**, а не данные. Это может привести к двойному освобождению.

---

## 🔹 Типичные ошибки

| Ошибка | Что не так |
|--------|-----------|
| Забыли `;` после `}` | Синтаксическая ошибка |
| `s->name` для обычной структуры | Нужно `s.name` |
| `s.name` для указателя | Нужно `s->name` |
| `s = {"Иванов", 18};` после объявления | Так нельзя — только при инициализации |
| `struct A a, b; if (a == b)` | Сравнение структур не работает |
| `strcpy(s.name, "текст")` | Для массива строк — `strcpy`, не `=` |
| Чтение не того поля `union` | Данные непредсказуемы |
| Забыли `typedef` перед `struct` | Приходится писать `struct Name` |

## 🔹 Быстрые примеры

**Структура + typedef + функция:**

```c
typedef struct {
    char name[50];
    int age;
} Person;

void print(const Person *p) {
    printf("%s, %d\n", p->name, p->age);
}

int main(void) {
    Person p = {"Иванов", 18};
    print(&p);
    return 0;
}
```

**Union для экономии памяти:**

```c
typedef union {
    int i;
    float f;
    char str[20];
} Data;

Data d;
d.i = 42;
```

**Тег + union (вариант):**

```c
typedef struct {
    int type;    // 0 = int, 1 = float
    union {
        int i;
        float f;
    } value;
} Variant;

Variant v;
v.type = 0;
v.value.i = 42;
```

## 🔹 Шпаргалка-сводка

| Что | Как |
|-----|-----|
| Объявить структуру | `struct Name { ... };` |
| Дать короткое имя | `typedef struct { ... } Name;` |
| Создать переменную | `Name s;` |
| Доступ к полю | `s.field` |
| Доступ через указатель | `p->field` |
| Размер | `sizeof(struct Name)` |
| Инициализация | `Name s = {значения};` |
| Объединение | `union Name { ... };` |
| Размер union | `sizeof(union Name)` |
| Сравнение структур | Сравнивать поля по одному |
| Копирование | `b = a;` (только для структур, не массивов) |
| Вложенные структуры | `s.inner.field` |

---

**Главное правило:** `struct` — для **одновременного** хранения разных данных, `union` — для **взаимоисключающих** (одно из). `typedef` делает код **короче и читаемее**. Всё вместе — основа для создания сложных типов данных, списков, деревьев и моделей реального мира.
