## 2. Память и адреса

Когда программа работает, все переменные лежат в оперативной памяти. Каждая ячейка памяти имеет свой номер — **адрес**. По сути, адрес — это просто число, которое говорит, где именно в памяти находится переменная.

Представьте шкаф с пронумерованными ящиками. Переменная — это содержимое ящика, а адрес — номер ящика. В C можно работать и с содержимым, и с номером.

```c
int x = 42;
printf("%d\n", x);     // содержимое: 42
printf("%p\n", &x);    // адрес: например, 0x7ffee4b8c9ac
```

Оператор `&` (амперсанд) даёт **адрес** переменной. Результат — число, но его принято выводить в шестнадцатеричном виде через `%p`.

## 3. Что такое указатель

**Указатель** — это переменная, которая хранит **адрес** другой переменной.

```c
int x = 42;
int *p = &x;    // p хранит адрес x
```

Читается так: «`p` — указатель на `int`, присваиваем ему адрес `x`».

Тип указателя важен: он говорит компилятору, **сколько байт** читать по этому адресу и как интерпретировать данные. Указатель на `int` и указатель на `char` — разные типы, даже если оба хранят одно и то же число.

```c
int *pi;      // указатель на int
char *pc;     // указатель на char
double *pd;   // указатель на double
```

## 4. Разыменование

**Разыменование** — это операция «достать значение по адресу». Обозначается звёздочкой `*`.

```c
int x = 42;
int *p = &x;

printf("%d\n", *p);   // 42 — значение по адресу
*p = 100;             // изменяем x через указатель
printf("%d\n", x);    // 100
```

Здесь `*p` — это уже **не указатель**, а обычное значение типа `int`. Через `*p = ...` можно менять оригинальную переменную, потому что мы пишем прямо в её ячейку памяти.

⚠️ Один и тот же символ `*` используется в двух ролях:
- в объявлении `int *p` — это часть типа («указатель на int»);
- в выражении `*p` — это операция разыменования.

Компилятор различает их по контексту.

## 5. Зачем нужны указатели

На первых порах кажется, что можно обойтись без указателей. Но они нужны для нескольких вещей:

1. **Изменение переменных в функциях.** В C аргументы передаются по значению — функция получает копию. Чтобы изменить оригинал, нужно передать адрес.

```c
void inc(int *x) {
    (*x)++;
}

int main(void) {
    int a = 5;
    inc(&a);
    printf("%d\n", a);   // 6
    return 0;
}
```

2. **Работа с массивами и строками.** Имя массива — это по сути указатель на его первый элемент.

3. **Динамическая память.** `malloc` возвращает указатель на выделенный блок.

4. **Структуры данных.** Списки, деревья, графы — всё строится на указателях.

## 6. Связь массивов и указателей

Имя массива в большинстве выражений **превращается в указатель** на первый элемент.

```c
int a[5] = {10, 20, 30, 40, 50};

printf("%d\n", a[0]);    // 10
printf("%d\n", *a);      // 10 — то же самое
printf("%d\n", *(a+1));  // 20
printf("%d\n", a[1]);    // 20 — то же самое
```

Выражения `a[i]` и `*(a + i)` **эквивалентны**. Это не магия, а определение индексации в C: `a[i]` компилятор превращает в `*(a + i)`.

При этом есть и различия:

| Свойство | Массив `int a[5]` | Указатель `int *p` |
|----------|-------------------|---------------------|
| Размер | `sizeof(a)` = 20 байт | `sizeof(p)` = 8 байт (на 64-bit) |
| Можно присвоить | ❌ `a = ...` нельзя | ✅ `p = ...` можно |
| Хранение | Сами данные | Адрес данных |

## 7. Арифметика указателей

С указателями можно выполнять арифметические операции, но с оговоркой: **шаг зависит от типа**.

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;    // p указывает на a[0]

printf("%d\n", *p);       // 10
p++;                      // теперь p указывает на a[1]
printf("%d\n", *p);       // 20
p += 2;                   // сдвиг на 2 элемента вперёд
printf("%d\n", *p);       // 40
```

Размер шага:

| Тип указателя | Шаг при `p++` |
|---------------|:-------------:|
| `char *` | 1 байт |
| `int *` | 4 байта |
| `double *` | 8 байт |

То есть `p++` для `int *` увеличивает адрес на 4, а не на 1. Компилятор сам умножает на `sizeof(int)`.

**Разность указателей** даёт количество элементов между ними:

```c
int a[5];
int *p1 = &a[1];
int *p2 = &a[4];
printf("%ld\n", p2 - p1);   // 3
```

## 8. Указатели и функции

Когда массив передаётся в функцию, передаётся **указатель на первый элемент**, а не копия всего массива. Поэтому изменения внутри функции видны снаружи.

```c
void fill(int *arr, int n, int value) {
    for (int i = 0; i < n; i++) {
        arr[i] = value;
    }
}

int main(void) {
    int a[5];
    fill(a, 5, 7);
    // теперь все элементы a равны 7
    return 0;
}
```

Обратите внимание: в функцию передаётся `a`, а не `&a`. Имя массива уже само по себе — адрес.

Если нужно изменить **сам указатель** внутри функции, передают указатель на указатель:

```c
void set_null(int **pp) {
    *pp = NULL;
}
```

## 9. Типичные ошибки

| Ошибка | Что не так |
|--------|-----------|
| `int *p; *p = 5;` | Указатель не инициализирован, пишем в мусорный адрес |
| `p = 5;` | Присваиваем указателю число, а не адрес |
| `*p = &x;` | Разыменовываем и присваиваем адрес — несоответствие типов |
| `int *p = 0x1234;` | Адрес должен быть получен через `&` или `malloc` |
| `p + 1` для `void *` | Арифметика с `void *` запрещена (размер неизвестен) |
| Сравнение указателей разных типов | Компилятор предупредит, поведение неопределено |

Совет: если не уверены, инициализируйте указатель `NULL` и проверяйте перед использованием.

```c
int *p = NULL;
if (p != NULL) {
    *p = 5;
}
```

## 10. Пример: копирование строки

Разберём, как связаны указатели и массивы на практике.

```c
#include <stdio.h>

void my_strcpy(char *dst, const char *src) {
    while (*src) {
        *dst = *src;
        dst++;
        src++;
    }
    *dst = '\0';
}

int main(void) {
    char src[] = "Hello";
    char dst[20];

    my_strcpy(dst, src);
    printf("%s\n", dst);   // Hello

    return 0;
}
```

Здесь:
- `*src` — текущий символ;
- `while (*src)` — цикл, пока не дошли до `'\0'`;
- `dst++`, `src++` — сдвигаем указатели на следующий символ;
- `*dst = '\0'` — завершаем строку.

Тот же код можно записать компактнее, но суть та же.

## 11. Итоги

- Указатель хранит **адрес** переменной.
- `&` — взять адрес, `*` — разыменовать.
- Имя массива — указатель на первый элемент.
- `a[i]` эквивалентно `*(a + i)`.
- Арифметика указателей зависит от типа: `p++` сдвигает на `sizeof(тип)`.
- Указатели позволяют функциям изменять оригинальные данные.
- Неинициализированный указатель — источник ошибок. Инициализируйте `NULL`.
