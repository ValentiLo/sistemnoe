## 2. Что такое утилита и чем она отличается от скрипта

**Скрипт** — просто набор команд для одной задачи.  
**Утилита** — это **инструмент**, который:

- Работает с **аргументами** и **опциями**.
- Имеет **справку** (`--help`).
- Обрабатывает **ошибки**.
- Возвращает **корректные коды** завершения.
- Понятна другим пользователям.

**Разница в подходе:**
- Скрипт «для себя» — писать быстро.
- Утилита «для всех» — писать аккуратно.

## 3. Типовая структура утилиты

```bash
#!/bin/bash
#
# Название: myutil
# Описание: краткое описание утилиты
# Автор: Имя Фамилия
# Дата: 2026-09-22
# Версия: 1.0
#

set -euo pipefail   # строгий режим

# --- Константы ---
VERSION="1.0"
PROGNAME="$(basename "$0")"

# --- Функции ---
usage() { ... }
log()   { ... }
error() { ... }

# --- Разбор аргументов ---
parse_args() { ... }

# --- Основная логика ---
main() { ... }

# --- Запуск ---
main "$@"
```

**Ключевые моменты:**

| Часть | Зачем нужна |
|-------|-------------|
| Shebang | Указывает интерпретатор |
| Заголовок | Описание, автор, версия |
| `set -euo pipefail` | Строгий режим |
| `usage` | Справка |
| `log`, `error` | Логирование |
| `parse_args` | Разбор аргументов |
| `main` | Основная логика |

## 4. Строгий режим `set -euo pipefail`

Одна строка, которая **сильно** улучшает надёжность скрипта:

```bash
set -euo pipefail
```

**Что означает:**

| Опция | Что делает |
|-------|-----------|
| `-e` | Останавливать скрипт при ошибке любой команды |
| `-u` | Ошибка при обращении к неинициализированной переменной |
| `-o pipefail` | Ошибка в конвейере, если **любая** команда упала |

⚠️ **Полезно, но требует аккуратности.** Например, `grep` возвращает 1, если ничего не нашёл, — и `-e` его остановит. Тогда:

```bash
if ! grep -q "pattern" file; then
    echo "Не найдено"
fi
```

Или временно отключить:

```bash
set +e
команда_которая_может_упасть
set -e
```

## 5. Справка `usage`

Каждая утилита должна уметь показать, как её использовать:

```bash
usage() {
    cat << EOF
Использование: $PROGNAME [опции] <файл>

Опции:
    -h, --help      Показать эту справку
    -v, --version   Показать версию
    -o, --output    Файл для результата (по умолчанию: output.txt)

Пример:
    $PROGNAME -o result.txt data.txt
EOF
}
```

**`cat << EOF`** — это **heredoc**, удобный способ записать многострочный текст.

**Вызов:**

```bash
if [ "$1" = "-h" ] || [ "$1" = "--help" ]; then
    usage
    exit 0
fi
```

## 6. Логирование

Функция для вывода сообщений:

```bash
log() {
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] $*"
}

error() {
    echo "[ОШИБКА] $*" >&2
}
```

**Использование:**

```bash
log "Начинаю работу"
log "Обрабатываю файл: $file"
error "Файл не найден: $file"
exit 1
```

⚠️ **Ошибки — в `stderr`** (`>&2`), чтобы их можно было отделить от обычного вывода.

## 7. Разбор аргументов

### Простой вариант

```bash
if [ $# -lt 1 ]; then
    usage
    exit 1
fi

input_file="$1"
```

### С опциями через `getopts`

```bash
output="output.txt"
verbose=0

while getopts "hvo:" opt; do
    case $opt in
        h) usage; exit 0 ;;
        v) verbose=1 ;;
        o) output="$OPTARG" ;;
        \?) error "Неизвестная опция"; usage; exit 1 ;;
    esac
done
shift $((OPTIND - 1))

# Теперь $1, $2, ... — позиционные аргументы
input_file="$1"
```

**Разбор `getopts "hvo:"`:**

| Символ | Что означает |
|--------|--------------|
| `h` | Флаг без аргумента |
| `v` | Флаг без аргумента |
| `o:` | Опция с аргументом (двоеточие!) |

### Длинные опции вручную

```bash
while [ $# -gt 0 ]; do
    case "$1" in
        -h|--help) usage; exit 0 ;;
        -v|--version) echo "$PROGNAME $VERSION"; exit 0 ;;
        -o|--output) output="$2"; shift ;;
        *) input_file="$1" ;;
    esac
    shift
done
```

## 8. Проверка входных данных

Всегда проверяйте, что получено то, что ожидалось:

```bash
# Файл существует?
if [ ! -f "$input_file" ]; then
    error "Файл не найден: $input_file"
    exit 1
fi

# Файл читаемый?
if [ ! -r "$input_file" ]; then
    error "Файл недоступен для чтения: $input_file"
    exit 1
fi

# Директория для вывода существует?
output_dir="$(dirname "$output")"
if [ ! -d "$output_dir" ]; then
    error "Каталог не существует: $output_dir"
    exit 1
fi
```

**Правило:** все проверки — **до** основной работы, чтобы не портить данные на середине.

## 9. Коды завершения

| Код | Что означает |
|:---:|--------------|
| 0 | Успех |
| 1 | Общая ошибка |
| 2 | Неверное использование (неправильные аргументы) |
| 126 | Нет прав на выполнение |
| 127 | Команда не найдена |
| 128 + N | Убит сигналом N |

**Пример:**

```bash
if [ ! -f "$input_file" ]; then
    error "Файл не найден"
    exit 1
fi

# успешное завершение
exit 0
```

## 10. Пример 1. Утилита для резервного копирования

```bash
#!/bin/bash
#
# backup.sh — резервное копирование каталога
#

set -euo pipefail

PROGNAME="$(basename "$0")"
VERSION="1.0"

usage() {
    cat << EOF
Использование: $PROGNAME [опции] <каталог>

Опции:
    -h, --help      Справка
    -v, --version   Версия
    -d, --dest DIR  Куда складывать архивы (по умолчанию: ./backups)

Пример:
    $PROGNAME -d /tmp/backups /home/user/docs
EOF
}

log() { echo "[$(date '+%H:%M:%S')] $*"; }
error() { echo "[ОШИБКА] $*" >&2; }

dest="./backups"

# Разбор опций
while [ $# -gt 0 ]; do
    case "$1" in
        -h|--help) usage; exit 0 ;;
        -v|--version) echo "$PROGNAME $VERSION"; exit 0 ;;
        -d|--dest) dest="$2"; shift ;;
        *) break ;;
    esac
    shift
done

if [ $# -lt 1 ]; then
    error "Не указан каталог для резервного копирования"
    usage
    exit 1
fi

src="$1"

if [ ! -d "$src" ]; then
    error "Каталог не найден: $src"
    exit 1
fi

mkdir -p "$dest"

timestamp=$(date '+%Y%m%d_%H%M%S')
archive="$dest/backup_${timestamp}.tar.gz"

log "Начинаю архивирование: $src"
tar -czf "$archive" "$src"

log "Готово: $archive"
log "Размер: $(du -h "$archive" | cut -f1)"
```

**Использование:**

```bash
./backup.sh -d /tmp/backups /home/user/docs
./backup.sh --help
```

## 11. Пример 2. Утилита для подсчёта статистики

```bash
#!/bin/bash
#
# stats.sh — статистика по файлам в каталоге
#

set -euo pipefail

PROGNAME="$(basename "$0")"

usage() {
    cat << EOF
Использование: $PROGNAME [каталог]

Подсчитывает количество файлов по типам и общий размер.
По умолчанию работает в текущем каталоге.
EOF
}

dir="${1:-.}"

if [ ! -d "$dir" ]; then
    echo "Каталог не найден: $dir" >&2
    exit 1
fi

declare -A count
declare -A size

total_files=0
total_size=0

while IFS= read -r -d '' file; do
    ext="${file##*.}"
    ext="${ext,,}"   # в нижний регистр
    fsize=$(stat -c %s "$file")

    count[$ext]=$(( ${count[$ext]:-0} + 1 ))
    size[$ext]=$(( ${size[$ext]:-0} + fsize ))

    total_files=$((total_files + 1))
    total_size=$((total_size + fsize))
done < <(find "$dir" -type f -print0)

echo "Статистика по каталогу: $dir"
echo "-----------------------------------------"
printf "%-10s %8s %12s\n" "Тип" "Файлов" "Байт"
for ext in "${!count[@]}"; do
    printf "%-10s %8d %12d\n" "$ext" "${count[$ext]}" "${size[$ext]}"
done | sort -k3 -n -r
echo "-----------------------------------------"
printf "%-10s %8d %12d\n" "ИТОГО" "$total_files" "$total_size"
```

**Использование:**

```bash
./stats.sh /home/user/projects
```

**Что показывает:**

```
Тип        Файлов         Байт
c              15       45000
h              12       12000
txt             5        3000
```

⚠️ **`declare -A`** — ассоциативный массив (ключ — строка). Требует Bash 4.0+.

## 12. Что важно в хорошей утилите

| Критерий | Как добиться |
|----------|--------------|
| Понятная справка | Функция `usage` |
| Обработка ошибок | `set -euo pipefail`, проверки |
| Логирование | Функции `log`, `error` |
| Коды завершения | `exit 0`, `exit 1` |
| Аргументы | `getopts` или ручной разбор |
| Читаемость | Функции, отступы, комментарии |
| Безопасность | Кавычки вокруг переменных |
| Переносимость | `#!/bin/bash`, не `/bin/sh` |

## 13. Типичные ошибки

| Ошибка | Что не так | Решение |
|--------|-----------|---------|
| Нет кавычек вокруг переменных | Разобьётся по пробелам | `"$var"` всегда |
| `rm -rf $dir/*` | Если `$dir` пусто — удалит всё | `[ -n "$dir" ] && rm -rf "$dir"/*` |
| Нет `set -e` | Ошибки игнорируются | Добавить строгий режим |
| Работа с `/bin/sh` | Нет bash-фич | `#!/bin/bash` |
| Нет проверки `$#` | Скрипт падает | Проверять число аргументов |
| Забыли `exit 0` | Неверный код возврата | Явный `exit 0` |
| `echo` с `-n` | Не переносимо | `printf` |

## 14. Итоги

- **Утилита** — инструмент, а не «просто скрипт».
- **Строгий режим** — `set -euo pipefail`.
- **Справка** — через `usage`.
- **Логирование** — `log`, `error` в `stderr`.
- **Аргументы** — `getopts` или ручной разбор.
- **Проверки** — до основной работы.
- **Коды завершения** — явные.
- **Кавычки** — вокруг всех переменных.
