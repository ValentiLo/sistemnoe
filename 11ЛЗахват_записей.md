## 1. Цели и задачи

**Цель:** разобраться, как организовать безопасный доступ к файлам из нескольких процессов одновременно.

**Задачи:**
- Понять, зачем нужны блокировки.
- Разобраться с типами блокировок: разделяемая и исключительная.
- Освоить `flock`, `fcntl`, `lockf`.
- Увидеть разницу между ними.

**Компетенции:** ОК 01, ОК 02, ПК 1.1, ПК 1.2.

---

## 2. Зачем нужны блокировки

Когда с одним файлом работают несколько процессов, возможны конфликты:

- Два процесса одновременно пишут в один файл — данные перемешаются.
- Один читает, другой в это время удаляет — читающий получит мусор.
- Два процесса одновременно меняют одну запись — результат непредсказуем.

**Блокировка** — это механизм, который позволяет одному процессу **временно** получить исключительный доступ к файлу или его части.

В Linux блокировки бывают **двух типов**:

| Тип | Что разрешает |
|-----|---------------|
| **Разделяемая (shared)** | Несколько процессов могут читать одновременно |
| **Исключительная (exclusive)** | Только один процесс имеет доступ |

---

## 3. Два вида блокировок

### Advisory (рекомендательная)

Это **договорённость** между процессами. Ядро **не проверяет** блокировку при обычных `read`/`write`. Если процесс **не использует** блокировки, он может спокойно читать и писать, игнорируя чужие блокировки.

**Плюс:** работает быстро, не требует поддержки файловой системы.  
**Минус:** работает только если **все** процессы соблюдают договорённость.

### Mandatory (принудительная)

Ядро **само проверяет** блокировки при `read`/`write` и **блокирует** процессы, которые пытаются нарушить блокировку. Это редко используется и требует специальной настройки файловой системы.

**На практике** почти всегда используется **advisory**-блокировка.

## 4. `flock` — простейшая блокировка

```c
#include <sys/file.h>

int flock(int fd, int operation);
```

**Что делает:** блокирует **весь файл** целиком.

**Операции:**

| Флаг | Значение |
|------|----------|
| `LOCK_SH` | Разделяемая блокировка (чтение) |
| `LOCK_EX` | Исключительная блокировка (запись) |
| `LOCK_UN` | Снять блокировку |
| `LOCK_NB` | Не блокировать (если занято — вернуть ошибку) |

**Пример:**

```c
int fd = open("file.txt", O_RDWR);

// Исключительная блокировка (ждём, если занято)
if (flock(fd, LOCK_EX) == -1) {
    perror("flock");
    close(fd);
    return 1;
}

// ... работа с файлом ...

flock(fd, LOCK_UN);   // снять блокировку
close(fd);
```

**Неблокирующий вариант:**

```c
if (flock(fd, LOCK_EX | LOCK_NB) == -1) {
    if (errno == EWOULDBLOCK) {
        printf("Файл занят другим процессом\n");
    }
    close(fd);
    return 1;
}
```

**Особенности `flock`:**
- Блокирует **весь файл** — нельзя заблокировать часть .
- Блокировка привязана к **открытому файлу** (`struct file`), а не к дескриптору.
- При `fork` ребёнок **наследует** блокировку.
- **Не работает на NFS** — используйте `fcntl` .

## 5. `fcntl` — мощная блокировка

```c
#include <fcntl.h>

int fcntl(int fd, int cmd, struct flock *lock);
```

**Что делает:** блокирует **файл или его часть** (запись). Стандарт POSIX.

**Команды:**

| Команда | Что делает |
|---------|-----------|
| `F_SETLK` | Установить блокировку (неблокирующая) |
| `F_SETLKW` | Установить блокировку (блокирующая, `W` = wait) |
| `F_GETLK` | Проверить, есть ли блокировка |
| `F_UNLCK` | Снять блокировку |

**Структура `struct flock`:**

```c
struct flock {
    short l_type;    // F_RDLCK, F_WRLCK, F_UNLCK
    short l_whence;  // SEEK_SET, SEEK_CUR, SEEK_END
    off_t l_start;   // начало блокировки
    off_t l_len;     // длина (0 = до конца файла)
    pid_t l_pid;     // PID процесса, держащего блокировку
};
```

**Типы блокировок:**

| Тип | Что означает |
|-----|--------------|
| `F_RDLCK` | Разделяемая (чтение) |
| `F_WRLCK` | Исключительная (запись) |
| `F_UNLCK` | Снять |

**Пример: блокировка всего файла**

```c
struct flock lck;

lck.l_type = F_WRLCK;      // исключительная
lck.l_whence = SEEK_SET;   // от начала
lck.l_start = 0;           // с нулевого байта
lck.l_len = 0;             // до конца файла

if (fcntl(fd, F_SETLK, &lck) == -1) {
    if (errno == EACCES || errno == EAGAIN) {
        printf("Файл занят\n");
    }
    close(fd);
    return 1;
}
```

**Пример: блокировка части файла (записи)**

```c
lck.l_type = F_WRLCK;
lck.l_whence = SEEK_SET;
lck.l_start = 100;         // с байта 100
lck.l_len = 10;            // 10 байт

fcntl(fd, F_SETLKW, &lck);   // блокирующая
```

**Особенности `fcntl`:**
- Можно блокировать **отдельные части** файла .
- Блокировка привязана к **процессу** (не к дескриптору).
- При `fork` ребёнок **не наследует** блокировку .
- Работает на **NFS** .
- Детектирует **дедлоки** .

## 6. `lockf` — упрощённая обёртка

```c
#include <unistd.h>

int lockf(int fd, int cmd, off_t len);
```

**Что делает:** упрощённый интерфейс над `fcntl` . Блокирует **с текущей позиции** до `len` байт.

**Команды:**

| Команда | Что делает |
|---------|-----------|
| `F_LOCK` | Исключительная (блокирующая) |
| `F_TLOCK` | Исключительная (неблокирующая) |
| `F_ULOCK` | Снять |
| `F_TEST` | Проверить |

**Пример:**

```c
int fd = open("file.txt", O_RDWR);

lseek(fd, 0, SEEK_SET);              // в начало

if (lockf(fd, F_TLOCK, 0) == -1) {   // 0 = весь файл
    perror("lockf");
    close(fd);
    return 1;
}

// ... работа ...

lockf(fd, F_ULOCK, 0);
close(fd);
```

**Особенности `lockf`:**
- Только **исключительные** блокировки (нет разделяемых) .
- Нужен `lseek` для указания позиции.
- Реализован через `fcntl` .

---

## 7. Сравнение

| Характеристика | `flock` | `fcntl` | `lockf` |
|----------------|:-------:|:-------:|:-------:|
| Уровень | Системный вызов | Системный вызов | Библиотечная функция |
| Блокировка | Весь файл | Частично | Частично |
| Разделяемая | ✅ | ✅ | ❌ |
| Блокирующая | ✅ | ✅ | ✅ |
| Неблокирующая | ✅ | ✅ | ✅ |
| Работа на NFS | ❌ | ✅ | ✅ |
| Наследование при `fork` | ✅ | ❌ | ❌ |
| Детект дедлока | ❌ | ✅ | ✅ |

**Правило:** для **простых задач** — `flock`. Для **гибких** — `fcntl`. `lockf` — редко, в основном для совместимости.

## 8. Практический пример: безопасная запись в файл

```c
#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <errno.h>
#include <string.h>

int main(void)
{
    int fd = open("shared.txt", O_RDWR | O_CREAT, 0644);
    if (fd == -1) {
        perror("open");
        return 1;
    }

    struct flock lck;
    lck.l_type = F_WRLCK;
    lck.l_whence = SEEK_SET;
    lck.l_start = 0;
    lck.l_len = 0;

    // Пытаемся получить блокировку
    if (fcntl(fd, F_SETLK, &lck) == -1) {
        if (errno == EACCES || errno == EAGAIN) {
            printf("Файл занят, ждём...\n");
            // Блокирующая попытка
            if (fcntl(fd, F_SETLKW, &lck) == -1) {
                perror("fcntl");
                close(fd);
                return 1;
            }
        }
    }

    // Критическая секция
    lseek(fd, 0, SEEK_END);
    const char *msg = "Запись с блокировкой\n";
    write(fd, msg, strlen(msg));

    // Снимаем блокировку
    lck.l_type = F_UNLCK;
    fcntl(fd, F_SETLK, &lck);

    close(fd);
    return 0;
}
```

## 9. Типичные ошибки

| Ошибка | Что не так |
|--------|-----------|
| Забыли снять блокировку | Другие процессы зависнут |
| `flock` на NFS | Не работает — использовать `fcntl` |
| Блокировка без `O_RDWR` | `F_WRLCK` требует записи |
| Ожидание без таймаута | Процесс может зависнуть навсегда |
| Дедлок | Два процесса ждут друг друга |
| Забыли закрыть `fd` | Блокировка снимется только при закрытии |

---

## 10. Итоги

- **Блокировки** защищают файл от одновременного доступа.
- **`flock`** — простой, весь файл, advisory.
- **`fcntl`** — мощный, части файла, POSIX.
- **`lockf`** — упрощённая обёртка над `fcntl`.
- **Advisory** — договорённость; **mandatory** — принудительно (редко).
- **Всегда снимайте** блокировку и **закрывайте** дескриптор.
