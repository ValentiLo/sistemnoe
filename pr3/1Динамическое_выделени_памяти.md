## 2. Краткая теория

### 2.1. Основные функции

| Функция | Что делает |
|---------|-----------|
| `malloc(n)` | Выделяет `n` байт |
| `calloc(k, s)` | Выделяет `k × s` байт и **обнуляет** |
| `realloc(p, n)` | Меняет размер блока до `n` байт |
| `free(p)` | Освобождает память |

Все объявлены в `<stdlib.h>`.

### 2.2. Правильный шаблон

```c
int *p = malloc(n * sizeof(int));
if (p == NULL) {
    perror("malloc");
    return 1;
}

// ... работа ...

free(p);
p = NULL;
```

### 2.3. Правила

1. **Проверяйте `NULL`** после `malloc`/`calloc`/`realloc`.
2. **Каждый `malloc` → `free`** — иначе утечка.
3. **После `free` → `p = NULL`** — защита от использования.
4. **Пишите `sizeof(тип)`**, а не число — так переносимо.
5. **Для строк: `malloc(strlen(s) + 1)`** — не забывайте `+1` для `'\0'`.

## 3. Задания для практической работы

### Задание 1. Динамический массив

**Условие:** запросить `n`, выделить массив из `n` целых, заполнить, вывести, освободить.

**Решение:**

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n;
    printf("Сколько чисел? ");
    scanf("%d", &n);

    int *arr = malloc(n * sizeof(int));
    if (arr == NULL) {
        perror("malloc");
        return 1;
    }

    for (int i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
    }

    printf("Массив: ");
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    free(arr);
    arr = NULL;
    return 0;
}
```

**Проверка:**
```
Ввод: 5
      1 2 3 4 5
Вывод: Массив: 1 2 3 4 5
```

### Задание 4. Динамическая строка

**Условие:** запросить строку, выделить память точно под неё (через `strlen + 1`), скопировать, вывести.

**Решение:**

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    char temp[1000];
    printf("Введите строку: ");
    scanf("%999s", temp);

    int len = strlen(temp);
    char *str = malloc(len + 1);
    if (str == NULL) {
        perror("malloc");
        return 1;
    }

    strcpy(str, temp);
    printf("Строка: %s\n", str);
    printf("Длина: %d\n", len);

    free(str);
    str = NULL;
    return 0;
}
```

⚠️ **`malloc(strlen(temp))` без `+1`** — ошибка: не хватит места для `'\0'`.

### Задание 6. `realloc` — увеличение массива

**Условие:** выделить массив из 3 элементов, затем расширить до 6 через `realloc`.

**Решение:**

```c
int *arr = malloc(3 * sizeof(int));
if (arr == NULL) { perror("malloc"); return 1; }

for (int i = 0; i < 3; i++) arr[i] = i + 1;

// Расширяем
int *tmp = realloc(arr, 6 * sizeof(int));
if (tmp == NULL) {
    perror("realloc");
    free(arr);
    return 1;
}
arr = tmp;

for (int i = 3; i < 6; i++) arr[i] = i + 1;

for (int i = 0; i < 6; i++) printf("%d ", arr[i]);
printf("\n");

free(arr);
```

**Вывод:** `1 2 3 4 5 6`

⚠️ **Не пишите `arr = realloc(arr, ...)`** — при ошибке потеряете старый указатель.

### Задание 7. Двумерный динамический массив

**Условие:** создать матрицу `rows × cols`, заполнить, вывести, освободить.

**Решение:**

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int rows = 3, cols = 4;

    // Выделяем массив указателей
    int **m = malloc(rows * sizeof(int *));
    if (m == NULL) { perror("malloc"); return 1; }

    // Выделяем каждую строку
    for (int i = 0; i < rows; i++) {
        m[i] = malloc(cols * sizeof(int));
        if (m[i] == NULL) {
            perror("malloc");
            for (int j = 0; j < i; j++) free(m[j]);
            free(m);
            return 1;
        }
    }

    // Заполняем
    for (int i = 0; i < rows; i++)
        for (int j = 0; j < cols; j++)
            m[i][j] = i * cols + j;

    // Выводим
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++)
            printf("%3d ", m[i][j]);
        printf("\n");
    }

    // Освобождаем
    for (int i = 0; i < rows; i++)
        free(m[i]);
    free(m);

    return 0;
}
```

⚠️ **Освобождать нужно в обратном порядке:** сначала строки, потом массив указателей.

### Задание 8. Динамический рост массива

**Условие:** читать числа с клавиатуры, пока не введён `0`, массив растёт по мере поступления.

**Решение:**

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int capacity = 2;
    int size = 0;
    int *arr = malloc(capacity * sizeof(int));
    if (arr == NULL) { perror("malloc"); return 1; }

    int x;
    while (scanf("%d", &x) == 1 && x != 0) {
        if (size == capacity) {
            capacity *= 2;
            int *tmp = realloc(arr, capacity * sizeof(int));
            if (tmp == NULL) {
                perror("realloc");
                free(arr);
                return 1;
            }
            arr = tmp;
        }
        arr[size++] = x;
    }

    printf("Введено чисел: %d\n", size);
    for (int i = 0; i < size; i++)
        printf("%d ", arr[i]);
    printf("\n");

    free(arr);
    return 0;
}
```

**Идея:** удваиваем размер, когда массив заполнен. Так работают `vector` в C++ и `list` в Python.

### Задание 9. Копирование строки

**Условие:** написать функцию, которая возвращает динамическую копию строки.

**Решение:**

```c
#include <stdlib.h>
#include <string.h>

char *my_strdup(const char *src)
{
    if (src == NULL) return NULL;

    int len = strlen(src);
    char *copy = malloc(len + 1);
    if (copy == NULL) return NULL;

    strcpy(copy, src);
    return copy;
}

int main(void)
{
    char *s = my_strdup("Привет, мир!");
    if (s == NULL) { perror("my_strdup"); return 1; }

    printf("%s\n", s);
    free(s);
    return 0;
}
```

⚠️ **Функция возвращает указатель на кучу** — вызывающий обязан `free`.

### Задание 10. Поиск утечек

**Условие:** найти утечку в предложенном фрагменте и исправить.

**Плохой код:**

```c
void process(void)
{
    int *a = malloc(100 * sizeof(int));
    int *b = malloc(200 * sizeof(int));

    // ... работа ...

    free(a);   // b забыли освободить — утечка!
}
```

**Исправление:**

```c
void process(void)
{
    int *a = malloc(100 * sizeof(int));
    int *b = malloc(200 * sizeof(int));

    if (a == NULL || b == NULL) {
        free(a);
        free(b);
        return;
    }

    // ... работа ...

    free(a);
    free(b);   // освобождаем оба
}
```

**Проверка через Valgrind:**

```bash
valgrind --leak-check=full ./app
```
