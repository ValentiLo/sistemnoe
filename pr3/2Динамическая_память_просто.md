# Динамическая память простыми словами

## Аналогия с рюкзаком

Представьте, что вы собираетесь в поход. У вас есть **рюкзак**, но вы не знаете заранее, сколько вещей возьмёте. Можно взять маленький — но вдруг не хватит. Можно большой — но вдруг останется место.

**Динамическая память** — это как **аренда ячейки нужного размера** в общем складе (куче). Вы говорите: «Мне нужно вот столько места», — и система выделяет.

---

## Четыре функции — четыре действия

### 1. `malloc(n)` — «дай мне место»

**Простыми словами:** «Выдели мне `n` байт памяти».

**Аналогия:** вы приходите на склад и говорите: «Мне нужна полка на 100 коробок». Кладовщик находит свободное место и даёт вам **адрес** этой полки (указатель).

```c
int *p = malloc(10 * sizeof(int));
```

**Что происходит:**
- Просим место под **10 целых чисел**.
- `sizeof(int)` — сколько байт занимает одно `int` (обычно 4).
- Итого — 40 байт.
- `p` — **адрес** этого места.

⚠️ **Важно:** в этой памяти **мусор**. Что было раньше — то и лежит. Никто не обнулил.

**Если места нет** — `malloc` вернёт `NULL`. Это как «Извините, склад переполнен».

```c
if (p == NULL) {
    printf("Не хватило памяти\n");
    return 1;
}
```

---

### 2. `calloc(k, s)` — «дай место и убери мусор»

**Простыми словами:** «Выдели `k × s` байт **и обнули** их».

**Аналогия:** та же полка, но кладовщик **сам вытер пыль** — все ячейки чистые (нули).

```c
int *p = calloc(10, sizeof(int));
```

**Что происходит:**
- `10` — сколько элементов.
- `sizeof(int)` — размер одного.
- Итого — 40 байт, **все равны 0**.

**Зачем это нужно:**
- Счётчики, флаги — сразу начинаются с нуля.
- Массивы, где важно начальное значение.

**Разница с `malloc`:**

| | `malloc` | `calloc` |
|--|:--------:|:--------:|
| Память | Мусор | Нули |
| Аргументы | Байты | Элементы × размер |
| Скорость | Чуть быстрее | Чуть медленнее |

---

### 3. `realloc(p, n)` — «измени размер»

**Простыми словами:** «Моё место стало мало (или много). Сделай его `n` байт».

**Аналогия:** у вас была полка на 10 коробок, теперь нужно 20. Кладовщик либо **расширяет** её на месте, либо **переносит** на новое место и **копирует** всё, что было.

```c
int *tmp = realloc(p, 20 * sizeof(int));
if (tmp == NULL) {
    free(p);        // старый блок ещё жив
    return 1;
}
p = tmp;            // обновляем указатель
```

**Что происходит:**
- Старые данные **сохраняются**.
- Новая часть — **мусор** (если увеличили).
- Указатель может **измениться** — блок мог переехать.

⚠️ **Главная ошибка новичков:**

```c
p = realloc(p, 20 * sizeof(int));   // ❌
```

Если `realloc` не сможет выделить память, он вернёт `NULL`, а старый `p` **потеряется** — память утечёт. **Всегда через временный указатель.**

---

### 4. `free(p)` — «верни место»

**Простыми словами:** «Мне больше не нужно — верни склад обратно».

**Аналогия:** вы уходите из похода — освобождаете полку. Кладовщик может отдать её другому.

```c
free(p);
p = NULL;     // защита от случайного использования
```

**Что происходит:**
- Память возвращается в **кучу**.
- Другие программы смогут её использовать.

⚠️ **Правила:**
- **Каждый `malloc` → `free`.**
- **`free(NULL)` безопасно** — ничего не делает.
- **Двойное `free`** — ошибка (краш).
- **После `free`** — указатель «висит», **не используйте его**.

## Полная картина

```
┌──────────────────────────────────────────────┐
│              КУЧА (heap)                     │
│                                              │
│  malloc(40)  → [ 40 байт ]  ← p              │
│  calloc(10,4) → [ 40 байт, нули ]  ← q       │
│  realloc(p, 80) → [ 80 байт ]  ← p (новый)  │
│  free(q)     → [ свободно ]                  │
└──────────────────────────────────────────────┘
```

**Жизненный цикл:**

```
выделил → проверил → использовал → освободил → обнулил указатель
```

## Шаблон, который надо выучить

```c
int *p = malloc(n * sizeof(int));   // 1. Выделить
if (p == NULL) {                     // 2. Проверить
    perror("malloc");
    return 1;
}

// 3. Использовать
for (int i = 0; i < n; i++) {
    p[i] = i;
}

free(p);                             // 4. Освободить
p = NULL;                            // 5. Обнулить
```

**Пять шагов — всегда.**

## Сравнение одним предложением

| Функция | Одним предложением |
|---------|--------------------|
| `malloc` | Дай мне место |
| `calloc` | Дай мне место и убери мусор |
| `realloc` | Измени размер моего места |
| `free` | Верни место |

---

## Простая таблица для запоминания

| Что нужно | Что использовать |
|-----------|------------------|
| Выделить память | `malloc` |
| Выделить и обнулить | `calloc` |
| Увеличить/уменьшить | `realloc` |
| Освободить | `free` |
| Проверить на ошибку | `if (p == NULL)` |
| Защитить от повторного `free` | `p = NULL` |

---

## Частые ошибки новичков

| Ошибка | Что не так |
|--------|-----------|
| Забыли `free` | Память утечёт |
| `free` дважды | Краш |
| Использование после `free` | Мусор / краш |
| `p = realloc(p, ...)` | Утечка при ошибке |
| `malloc(strlen(s))` без `+1` | Не хватит места для `'\0'` |
| Нет проверки `NULL` | Краш при нехватке памяти |

---

## Мнемоника

- **`m`**alloc = **m**emory (просто память)
- **`c`**alloc = **c**lear + alloc (память + очистка)
- **`re`**alloc = **re**-allocate (пере-выделить)
- **`free`** = освободить

**Запомните:** «**m**усор, **c**lean, **re**size, **f**ree» — malloc оставляет мусор, calloc чистит, realloc меняет размер, free освобождает.
