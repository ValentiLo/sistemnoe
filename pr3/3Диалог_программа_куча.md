# Конкретный пример: диалог «программа — куча» с диаграммами

Разберём **одну программу** по шагам и посмотрим, что происходит в памяти на каждом этапе.

---

## Программа

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    // Шаг 1. malloc
    int *a = malloc(3 * sizeof(int));
    if (a == NULL) return 1;
    a[0] = 10; a[1] = 20; a[2] = 30;

    // Шаг 2. calloc
    int *b = calloc(2, sizeof(int));
    if (b == NULL) { free(a); return 1; }
    b[0] = 100; b[1] = 200;

    // Шаг 3. realloc
    int *tmp = realloc(a, 5 * sizeof(int));
    if (tmp == NULL) { free(a); free(b); return 1; }
    a = tmp;
    a[3] = 40; a[4] = 50;

    // Шаг 4. free
    free(b);
    b = NULL;

    free(a);
    a = NULL;

    return 0;
}
```

---

## Шаг 0. Начальное состояние

```
Программа (стек)              Куча (heap)
┌──────────────┐             ┌──────────────────┐
│ a = ?        │             │                  │
│ b = ?        │             │   (пусто)        │
└──────────────┘             │                  │
                             └──────────────────┘
```

**Диалог:**
> *Программа:* — Мне пока ничего не нужно.
> *Куча:* — Свободна.

---

## Шаг 1. `malloc(3 * sizeof(int))`

```c
int *a = malloc(3 * sizeof(int));
```

**Диалог:**
> *Программа:* — Куча, дай мне **12 байт** (3 × 4) под целые числа.
> *Куча:* — Ищу свободное место... Нашла! Вот адрес: `0x1000`.

**Что произошло:**

```
Программа (стек)              Куча (heap)
┌──────────────┐             ┌──────────────────┐
│ a = 0x1000   │ ─────────→  │ [ ? ] [ ? ] [ ? ]│  ← 12 байт
│ b = ?        │             │  0x1000          │
└──────────────┘             └──────────────────┘
```

⚠️ **Внутри — мусор.** Что было до этого — то и лежит. Никто не обнулял.

**После заполнения:**

```c
a[0] = 10; a[1] = 20; a[2] = 30;
```

```
Программа (стек)              Куча (heap)
┌──────────────┐             ┌──────────────────┐
│ a = 0x1000   │ ─────────→  │ 10  │ 20  │ 30  │
│ b = ?        │             │ 0x1000           │
└──────────────┘             └──────────────────┘
```

---

## Шаг 2. `calloc(2, sizeof(int))`

```c
int *b = calloc(2, sizeof(int));
```

**Диалог:**
> *Программа:* — Куча, дай мне **8 байт** (2 × 4) **и обнули их**.
> *Куча:* — Ищу... Нашла! Вот адрес: `0x2000`. И сразу протёрла все байты — там нули.

**Что произошло:**

```
Программа (стек)              Куча (heap)
┌──────────────┐             ┌──────────────────┐
│ a = 0x1000   │ ─────────→  │ 10  │ 20  │ 30  │  ← 12 байт
│ b = 0x2000   │ ─────┐      ├──────────────────┤
└──────────────┘      │      │  0  │  0         │  ← 8 байт (нули!)
                      └────→ │  0x2000          │
                             └──────────────────┘
```

**После заполнения:**

```c
b[0] = 100; b[1] = 200;
```

```
Программа (стек)              Куча (heap)
┌──────────────┐             ┌──────────────────┐
│ a = 0x1000   │ ─────────→  │ 10  │ 20  │ 30  │
│ b = 0x2000   │ ─────┐      ├──────────────────┤
└──────────────┘      │      │ 100 │ 200        │
                      └────→ │  0x2000          │
                             └──────────────────┘
```

---

## Шаг 3. `realloc(a, 5 * sizeof(int))`

```c
int *tmp = realloc(a, 5 * sizeof(int));
```

**Диалог:**
> *Программа:* — Куча, у меня блок по адресу `0x1000`. Мне нужно **20 байт** (5 × 4) вместо 12.
> *Куча:* — Проверяю, свободно ли сразу после твоего блока... Да, есть место. Расширяю **на месте**.

**Вариант A: расширение на месте (адрес тот же)**

```
Программа (стек)              Куча (heap)
┌──────────────┐             ┌────────────────────────────┐
│ a = 0x1000   │ ─────────→  │ 10 │ 20 │ 30 │ ?  │ ?     │
│ tmp = 0x1000 │             │  0x1000                    │
│ b = 0x2000   │ ─────┐      ├────────────────────────────┤
└──────────────┘      │      │ 100 │ 200                  │
                      └────→ │  0x2000                    │
                             └────────────────────────────┘
```

**Вариант B: переезд (адрес другой)**

Если места после блока нет — `realloc` ищет **новое** место, **копирует** данные, **освобождает** старое.

```
Программа (стек)              Куча (heap)
┌──────────────┐             ┌────────────────────────────┐
│ a = 0x3000   │ ─────────→  │ 10 │ 20 │ 30 │ ?  │ ?     │  ← новый адрес
│ tmp = 0x3000 │             │  0x3000                    │
│ b = 0x2000   │ ─────┐      ├────────────────────────────┤
└──────────────┘      │      │ (свободно)                 │  ← старое место
                             ├────────────────────────────┤
                             │ 100 │ 200                  │
                      └────→ │  0x2000                    │
                             └────────────────────────────┘
```

⚠️ **Нельзя писать `a = realloc(a, ...)`** — если `realloc` вернёт `NULL`, старый `a` потеряется.

**После заполнения новых ячеек:**

```c
a[3] = 40; a[4] = 50;
```

```
Программа (стек)              Куча (heap)
┌──────────────┐             ┌────────────────────────────┐
│ a = 0x3000   │ ─────────→  │ 10 │ 20 │ 30 │ 40 │ 50    │
│ tmp = 0x3000 │             │  0x3000                    │
│ b = 0x2000   │ ─────┐      ├────────────────────────────┤
└──────────────┘      │      │ 100 │ 200                  │
                      └────→ │  0x2000                    │
                             └────────────────────────────┘
```

## Шаг 4. `free(b)`

```c
free(b);
b = NULL;
```

**Диалог:**
> *Программа:* — Куча, блок по адресу `0x2000` мне больше не нужен. Забирай.
> *Куча:* — Приняла. Помечаю его как свободный.

**Что произошло:**

```
Программа (стек)              Куча (heap)
┌──────────────┐             ┌────────────────────────────┐
│ a = 0x3000   │ ─────────→  │ 10 │ 20 │ 30 │ 40 │ 50    │
│ b = NULL     │             │  0x3000                    │
└──────────────┘             ├────────────────────────────┤
                             │ (свободно)                 │  ← 0x2000
                             └────────────────────────────┘
```

⚠️ **`b = NULL`** — защита от случайного использования. Теперь `b` не указывает никуда, и если случайно обратиться к `*b`, программа сразу упадёт с понятной ошибкой, а не будет работать с «мусором».

---

## Шаг 5. `free(a)`

```c
free(a);
a = NULL;
```

**Диалог:**
> *Программа:* — Куча, блок `0x3000` тоже свободен. Забирай.
> *Куча:* — Приняла. Вся память свободна.

**Что произошло:**

```
Программа (стек)              Куча (heap)
┌──────────────┐             ┌────────────────────────────┐
│ a = NULL     │             │ (свободно)                 │
│ b = NULL     │             │                            │
└──────────────┘             │                            │
                             └────────────────────────────┘
```

**Программа завершается.**

---

## Сводная диаграмма: вся жизнь программы

| Шаг | Программа | Куча (что занято) | Что произошло |
|:---:|-----------|-------------------|---------------|
| 0 | `a = ?`, `b = ?` | пусто | Старт |
| 1 | `a = 0x1000` | 12 байт (мусор) | `malloc` |
| 2 | `b = 0x2000` | 12 + 8 байт (нули) | `calloc` |
| 3 | `a = 0x3000` | 20 + 8 байт | `realloc` (переезд) |
| 4 | `b = NULL` | 20 байт | `free(b)` |
| 5 | `a = NULL` | пусто | `free(a)` |

---

## Что было бы без `free`

Если убрать `free(a)` и `free(b)`:

```
Программа (стек)              Куча (heap)
┌──────────────┐             ┌────────────────────────────┐
│ a = 0x3000   │             │ 10 │ 20 │ 30 │ 40 │ 50    │  ← занято
│ b = 0x2000   │             │  0x3000                    │
└──────────────┘             ├────────────────────────────┤
                             │ 100 │ 200                  │  ← занято
                             │  0x2000                    │
                             └────────────────────────────┘
```

⚠️ **Программа завершилась — но память осталась «занятой» с точки зрения системы.** В больших программах это приводит к тому, что свободная память заканчивается, и `malloc` начинает возвращать `NULL`. Это и есть **утечка памяти**.

---

## Мини-диалог «программа — куча» для каждой функции

| Функция | Что говорит программа | Что отвечает куча |
|---------|----------------------|-------------------|
| `malloc(12)` | «Дай 12 байт» | «Вот адрес 0x1000. Внутри мусор» |
| `calloc(2, 4)` | «Дай 8 байт и обнули» | «Вот адрес 0x2000. Всё в нулях» |
| `realloc(p, 20)` | «Расширь мой блок до 20 байт» | «Либо расширяю на месте, либо копирую в новое место» |
| `free(p)` | «Блок больше не нужен» | «Помечаю как свободный» |

---

## Как это выглядит «в голове»

```
1. malloc  → «дай место»           → указатель на мусор
2. calloc  → «дай место и обнули»  → указатель на нули
3. realloc → «измени размер»       → тот же или новый указатель, данные сохранены
4. free    → «верни место»         → указатель «висит», ставим NULL
```

---

## Итог

- **`malloc`** — даёт **мусор**, нужно заполнять самому.
- **`calloc`** — даёт **нули**, готово к использованию.
- **`realloc`** — **сохраняет** данные, может **переехать**.
- **`free`** — **возвращает** память, **обнуляем** указатель.
- **Без `free`** — утечка, свободная память кончается.
- **Пять шагов** в любой программе: выделить → проверить → использовать → освободить → обнулить.
