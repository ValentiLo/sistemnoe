**Дисциплина:** Основы программирования на языке Си

## 1. Цели и задачи

**Цель:** научиться создавать и завершать потоки с помощью библиотеки POSIX Threads.

**Задачи:**
- Понять, чем поток отличается от процесса.
- Освоить `pthread_create` — создание потока.
- Освоить `pthread_join` — ожидание завершения.
- Разобраться с передачей аргументов и возвратом результата.

**Компетенции:** ОК 01, ОК 02, ПК 1.1, ПК 1.2.

## 2. Процесс vs поток

**Процесс** — тяжёлая единица. Своё адресное пространство, свои дескрипторы, своя память.

**Поток** — лёгкая единица **внутри** процесса. Все потоки одного процесса **разделяют**:

| Что делится | Что у каждого своё |
|-------------|---------------------|
| Адресное пространство | Стек |
| Открытые файлы | Регистры |
| Переменные окружения | Программный счётчик |
| Сигналы | Локальные переменные |

**Плюсы потоков:**
- Создать поток **дешевле**, чем процесс.
- Обмен данными через **общую память** — быстро.
- Переключение между потоками **быстрее**.

**Минусы:**
- Нужна **синхронизация** (гонки, мьютексы).
- Ошибка в одном потоке может уронить весь процесс.

---

## 3. Подключение библиотеки

POSIX Threads (pthreads) — часть стандартной библиотеки Linux. Подключается:

```c
#include <pthread.h>
```

**При компиляции** нужен флаг **`-pthread`**:

```bash
gcc -Wall -Wextra -g -pthread -o app main.c
```

Без этого — ошибка компоновки `undefined reference to 'pthread_create'`.

---

## 4. `pthread_create` — создание потока

```c
#include <pthread.h>

int pthread_create(
    pthread_t *thread,                  // ID потока
    const pthread_attr_t *attr,         // атрибуты (NULL = по умолчанию)
    void *(*start_routine)(void *),     // функция потока
    void *arg                           // аргумент функции
);
```

**Возвращает:** `0` при успехе, код ошибки при неудаче.

⚠️ **`pthread_create` возвращает код ошибки, а не `errno`.** Проверять нужно **сам возврат**, а не `errno`.

**Функция потока** должна иметь сигнатуру:

```c
void *имя_функции(void *arg);
```

- Принимает **один указатель**.
- Возвращает **указатель**.

**Простейший пример:**

```c
#include <stdio.h>
#include <pthread.h>

void *worker(void *arg)
{
    printf("Привет из потока!\n");
    return NULL;
}

int main(void)
{
    pthread_t tid;

    if (pthread_create(&tid, NULL, worker, NULL) != 0) {
        perror("pthread_create");
        return 1;
    }

    printf("Привет из main!\n");

    pthread_join(tid, NULL);
    return 0;
}
```

⚠️ **Порядок вывода не гарантирован** — потоки работают параллельно.

## 5. `pthread_join` — ожидание потока

```c
int pthread_join(pthread_t thread, void **retval);
```

**Что делает:** ждёт завершения указанного потока.

**Параметры:**
- `thread` — ID потока.
- `retval` — куда сохранить возвращённое значение. Можно `NULL`.

**Возвращает:** `0` при успехе, код ошибки.

**Пример с возвратом:**

```c
void *worker(void *arg)
{
    int *result = malloc(sizeof(int));
    *result = 42;
    return result;
}

int main(void)
{
    pthread_t tid;
    pthread_create(&tid, NULL, worker, NULL);

    void *ret;
    pthread_join(tid, &ret);

    int value = *(int *)ret;
    printf("Результат: %d\n", value);

    free(ret);
    return 0;
}
```

⚠️ **Возвращаемое значение должно быть в куче** (`malloc`) или статическим. **Нельзя** возвращать указатель на локальную переменную — она уничтожится при выходе из потока.

## 6. Передача аргументов

Функция потока принимает **один** указатель. Если нужно передать несколько значений — используйте структуру.

```c
typedef struct {
    int start;
    int end;
} Range;

void *sum_range(void *arg)
{
    Range *r = (Range *)arg;
    int sum = 0;
    for (int i = r->start; i < r->end; i++) {
        sum += i;
    }
    return (void *)(long)sum;
}

int main(void)
{
    Range r = {1, 100};
    pthread_t tid;
    pthread_create(&tid, NULL, sum_range, &r);

    void *ret;
    pthread_join(tid, &ret);
    printf("Сумма: %ld\n", (long)ret);

    return 0;
}
```

⚠️ **Аргумент `&r` живёт в стеке `main`.** Убедитесь, что `main` не завершится, пока поток использует `r`. Иначе — UB. В примере `pthread_join` это гарантирует.

## 7. Что происходит, если не вызвать `join`

Если `main` завершится **раньше** потоков — программа закончится, и потоки будут **прерваны**. Возможны два варианта:

- **`return` из `main`** — процесс завершается, все потоки убиваются.
- **`pthread_exit(NULL)` из `main`** — процесс ждёт завершения остальных потоков.

**Пример:**

```c
int main(void)
{
    pthread_t tid;
    pthread_create(&tid, NULL, worker, NULL);

    pthread_exit(NULL);   // ждём завершения потоков
}
```

⚠️ Но **правильнее** — использовать `pthread_join`.

## 8. Возврат значения из потока

Есть **три** способа вернуть результат:

**1. Через указатель (malloc):**

```c
void *worker(void *arg)
{
    int *r = malloc(sizeof(int));
    *r = 42;
    return r;
}
```

**2. Через структуру-аргумент:**

```c
typedef struct {
    int input;
    int output;
} Job;

void *worker(void *arg)
{
    Job *j = (Job *)arg;
    j->output = j->input * 2;
    return NULL;
}
```

**3. Через глобальную переменную** — просто, но небезопасно без синхронизации.

**Рекомендация:** для сложных результатов — **структура**, для простых — `malloc`.

## 9. Полный пример: два потока

```c
#include <stdio.h>
#include <pthread.h>
#include <stdlib.h>

void *worker1(void *arg)
{
    printf("Поток 1 начал работу\n");
    sleep(2);
    printf("Поток 1 завершился\n");
    return (void *)1;
}

void *worker2(void *arg)
{
    printf("Поток 2 начал работу\n");
    sleep(1);
    printf("Поток 2 завершился\n");
    return (void *)2;
}

int main(void)
{
    pthread_t t1, t2;

    pthread_create(&t1, NULL, worker1, NULL);
    pthread_create(&t2, NULL, worker2, NULL);

    void *ret1, *ret2;
    pthread_join(t1, &ret1);
    pthread_join(t2, &ret2);

    printf("Результат 1: %ld\n", (long)ret1);
    printf("Результат 2: %ld\n", (long)ret2);

    return 0;
}
```

**Возможный вывод:**

```
Поток 1 начал работу
Поток 2 начал работу
Поток 2 завершился
Поток 1 завершился
Результат 1: 1
Результат 2: 2
```

## 10. Сравнение с процессами

| Характеристика | Процессы | Потоки |
|----------------|:--------:|:------:|
| Создание | `fork` | `pthread_create` |
| Ожидание | `wait`/`waitpid` | `pthread_join` |
| Память | Своя | Общая |
| Обмен | Через IPC | Через переменные |
| Переключение | Дорогое | Дешёвое |
| Синхронизация | `pipe`, `shm` | Мьютексы |

## 11. Типичные ошибки

| Ошибка | Что не так | Решение |
|--------|-----------|---------|
| Нет `-pthread` при компиляции | `undefined reference` | Добавить флаг |
| Не проверяют возврат `pthread_create` | Ошибка останется незамеченной | Проверять |
| Возвращают указатель на локальную переменную | UB | Возвращать `malloc` |
| Не вызывают `pthread_join` | Потоки могут не завершиться | Ждать всегда |
| Передают указатель на локальную переменную из `main` | Может исчезнуть | Убедиться, что живёт |
| Путают `pthread_join` с `wait` | Разные API | Использовать правильно |
| Смешивают `printf` из потоков без синхронизации | Перемешанный вывод | Синхронизировать |

## 12. Итоги

- **Поток** — лёгкая единица внутри процесса, разделяет память.
- **`pthread_create`** — создаёт поток; возвращает **код ошибки**, не `errno`.
- **`pthread_join`** — ждёт завершения потока.
- **Функция потока** — `void *f(void *arg)`.
- **Аргументы** — через указатель на структуру.
- **Результат** — через `malloc` или структуру.
- **Компиляция** — обязательно с `-pthread`.
- **Без `join`** — поток может быть прерван при завершении `main`.
